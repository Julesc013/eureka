# Temporal Minimal Search Notes v0

This note is contract evidence only. It sketches future projection posture for
Temporal Minimal Search without adding CSS, renderer code, or generated static
site artifacts.

- Use text links before decorative controls.
- Keep source, evidence, risk, rights, limitations, gaps, absence scope, and
  blocked actions visible.
- Prefer ordinary GET forms for search-like input.
- Permit high contrast, text-only, print, file-tree, terminal-future, and
  native-card-future profiles without changing route meaning.
