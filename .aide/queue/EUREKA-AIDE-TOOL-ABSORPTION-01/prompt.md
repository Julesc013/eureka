`discover -> classify -> wrap -> adapt -> migrate -> retire with evidence`

Required output is a Q56 queue packet, generated `.aide/tools/**` inventories and wrap plans, top-level Eureka reports, and a Q57 task packet for `Q57 Eureka Source Observation Vertical Slice Plan`.
