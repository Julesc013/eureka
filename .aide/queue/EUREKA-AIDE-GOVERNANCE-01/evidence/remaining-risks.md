# Remaining Risks

- Existing historical commits do not all follow the new Markdown body standard.
- The optional Git hook template is committed, but local hook installation is
  operator/machine-local and not enforced by Git until configured.
- The task-resumption policy improves future agent behavior but cannot prove
  arbitrary task ordering will always be conflict-free.
- AIDE remains repo governance and validation support, not Eureka product truth.
