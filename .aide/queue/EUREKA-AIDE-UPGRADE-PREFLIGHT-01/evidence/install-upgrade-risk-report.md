# Install / Upgrade Risk Report

## Upgrade Mode

`.aide/` exists and validates, so Q55 must be an upgrade, not a fresh install.

## Preservation Requirements

Q55 must preserve:

- `.aide/memory/**`;
- `.aide/queue/**`;
- `.aide/evals/**`, including Eureka-specific golden tasks;
- `.aide/context/latest-*` unless deliberately regenerated by target AIDE commands;
- `.aide/reports/**` target reports and token evidence;
- `.aide/git/**`, `.aide/changelog/**`, route/cache/provider/gateway report-only state unless intentionally regenerated;
- `AGENTS.md` manual content and managed-section boundaries;
- architecture checks, validators, scripts, tests, command matrix, and test/eval lane docs;
- source/evidence/index contracts, validators, reports, stores, fixtures, and examples;
- product source roots and generated public/static artifacts;
- target-specific patches from Q22/Q26/Q32 and later.

## Avoidance Requirements

Q55 must avoid:

- `.aide.local/**`, `.env`, secrets, raw prompts, raw responses, provider credentials;
- branch mutation, push, merge, rebase, tag, release publication, active CI installation;
- product behavior changes;
- live probes, crawlers, downloads, source-sync, public index mutation, evidence ledger mutation;
- importing source AIDE `.aide/queue/**`, source memory, source generated context, source Git helper state, or source reports as Eureka truth.

## Conflict Risks

- Local `dev` is ahead 9 and behind 6 relative to `origin/dev` at Q54 inspection; HUNT work is active remotely.
- A pre-existing untracked native build-output path exists: `native/win/winforms/src/Eureka/obj/`.
- Existing gateway/provider status subcommands fail because source-repo `core.*` modules are missing from the target install.
- Existing `pack-status` is not meaningful in Eureka because target repos do not carry the source export pack under `.aide/export/aide-lite-pack-v0`.
- Stable bundle contains many new planning surfaces that may overlap with current target AIDE policies, generated reports, golden tasks, and adapter guidance.

## Required Q55 Approach

1. Re-run guard and record branch/worktree state.
2. Use upgrade observe/compare/plan/dry-run because `.aide/` exists.
3. Apply only portable AIDE files permitted by an explicit preservation policy.
4. Treat target memory, queue, reports, golden tasks, and product docs as target-owned.
5. Wrap existing Eureka tools instead of replacing them.
6. Leave product roots untouched.
7. Stop at a reviewable upgrade result with validation evidence.
