# Eureka AIDE Preservation Plan

Q55 must preserve target-owned Eureka state before applying portable AIDE files.

Preserve:

- `.aide/memory/**`
- `.aide/queue/**`
- `.aide/evals/**`
- `.aide/context/latest-*` unless regenerated by target commands
- `.aide/reports/**`, `.aide/git/**`, `.aide/changelog/**`
- `AGENTS.md` manual content and managed section boundaries
- Eureka-specific golden tasks, queue packets, handoff reports, repo-health reports, and token evidence
- architecture validators, command matrix, test/eval lanes, source/evidence/index validators, and product safety docs

Do not import from source AIDE as target truth:

- source `.aide/queue/**`
- source `.aide/memory/**`
- source generated context/reports/Git helper state
- source local state, secrets, raw prompts, raw responses

Q55 approach:

1. observe current target state;
2. compare bundle files to target files;
3. produce preservation/conflict plan;
4. dry-run upgrade;
5. apply only reviewed portable AIDE files;
6. rerun validation;
7. stop at review.
