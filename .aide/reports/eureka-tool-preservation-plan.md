# Eureka Tool Preservation Plan

Q56 preservation rule:

`discover -> classify -> wrap -> adapt -> migrate -> retire with evidence`

Preserve by default:

- Architecture checks and dependency boundary validators.
- Source observation, source cache, evidence ledger, public index, connector, source sync, and registry validators.
- Static site and snapshot validators.
- Command matrix and test lane docs.
- AIDE target-local scripts, memory, queue evidence, reports, generated packets, and golden tasks.
- Unknown, high-risk, release-sensitive, network-sensitive, source/evidence/index mutation-sensitive tools.

Q56 restrictions:

- No tool deletion.
- No tool rename.
- No tool move.
- No unknown tool execution.
- No source cache, evidence ledger, public index, registry, live probe, provider/model, release, CI, branch, or deployment mutation.

Future wrappers must be added in a reviewed queue phase and must record input/output contracts, safety gates, validation, and evidence before any migration or retirement is considered.
