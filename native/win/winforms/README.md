# WinForms Lane

Lane id: `win.winforms`.

This lane contains the C-BUNDLE-01 read-only proof project for .NET Framework
4.8 WinForms. The project is fixture-oriented: it reads local snapshot and relay
fixture examples, displays summaries, limitations, and blocked actions, and does
not call live sources, download files, install files, execute artifacts, collect
telemetry, authenticate accounts, or mutate indexes.
