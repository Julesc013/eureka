# Win32 Lane

Lane id: `win.win32`.

This lane contains the C-BUNDLE-02 Win32 ANSI read-only skeleton for Visual C++
6.0 style hosts. It consumes local snapshot, relay, and action-manifest fixture
text through native-facing adapters.

The skeleton is build-unverified unless opened and built on a suitable host. It
does not provide live access, downloads, installers, execution, account flows,
telemetry, source sync, or index mutation.
