# AppKit Lane

Lane id: `mac.appkit`.

This lane contains the C-BUNDLE-02 Objective-C AppKit read-only skeleton for an
Xcode 9.x style host. It consumes local snapshot, relay, and action-manifest
fixture text and displays limitations, blocked actions, and diagnostics.

The project folder is a documented placeholder, not a verified Xcode project.
No live access, downloads, installers, execution, credentials, telemetry, source
sync, or index mutation are enabled.
