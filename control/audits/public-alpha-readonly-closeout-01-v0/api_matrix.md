# API Matrix

Public alpha API routes are read-only:

- `/api/v1/alpha/status`
- `/api/v1/alpha/search`
- `/api/v1/alpha/object/{object_id}`
- `/api/v1/alpha/source/{summary_id}`
- `/api/v1/alpha/evidence/{summary_id}`
- `/api/v1/alpha/absence/{summary_id}`
- `/api/v1/alpha/needs`

Only `GET` and `HEAD` are allowed for the public alpha posture.
