# Hard Gate Matrix

The E2E reference-system track retains these gates across all child packets.

| Gate | Posture |
| --- | --- |
| New live-provider or network access | Separate authority required |
| Credentials or secrets | Separate authority required |
| Real Review Ledger decisions | Separate authority required |
| Real reviewed-record materialization | Separate authority required |
| Reviewed/master-index mutation | Separate authority required |
| Public-index mutation | Separate authority required |
| Public snapshot publication | Separate authority required |
| Public exposure | Separate authority required |
| Public launch | Separate authority required |
| Downloads or file payload fetching | Separate authority required |
| Installation, emulation, or execution | Separate authority required |
| License changes | Separate authority required |
| Destructive data migration | Separate authority required |
| Native/mobile distribution | Separate authority required |
| Rust replacement of reference semantics | Separate authority required |

Synthetic truth mechanics are allowed only in isolated test namespaces with no
real candidates, no production Review Ledger, no reviewed/master/public index,
mandatory rollback, and clearly synthetic outputs.
