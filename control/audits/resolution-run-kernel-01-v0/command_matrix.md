# Command Matrix

Allowed commands:

- `create_run`
- `plan_workunits`
- `build_lane_snapshot`
- `build_coverage_report`
- `cancel_run`

Blocked commands:

- live source probes
- live IA metadata
- download or upload
- extraction or execution
- model/provider calls
- operator, master, reviewed, review, source-cache, evidence, or candidate mutations
- deployment
- production/public launch claims
