# Source Registry V2 Summary

The H0 registry example contains eight source records:

- Internet Archive metadata
- Wayback/CDX/Memento
- GitHub Releases
- PyPI
- npm
- Software Heritage
- Retro community example
- Policy blocked source example

The registry is `no_live_source_access`. It does not enable source sync,
downloads, public fanout, public-index mutation, master-index mutation, or truth
acceptance.
