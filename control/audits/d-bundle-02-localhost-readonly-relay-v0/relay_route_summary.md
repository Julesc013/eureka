# Relay Route Summary

The route table covers `/status`, `/snapshot`, `/search`, `/object/{id}`,
`/source/{id}`, `/need/{id}`, `/action/{id}`, `/manifest`, `/files`,
`/text/search`, `/text/object/{id}`, and `/terminal`.

All routes are read-only fixture projections. POST, PUT, PATCH, DELETE, admin,
upload, download, execute, install, mirror, and write route families are
blocked.
