# Relay Profile Summary

D-BUNDLE-02 adds localhost-only, read-only relay profiles for fixture snapshots.
The current profile allows only `127.0.0.1` or `localhost`, GET routes, and
text/lite HTML/file-tree/JSON/terminal/native fixture projections.

Public bind, hosted relay, accounts, uploads, downloads, telemetry, action
execution, and live source access remain disabled.
