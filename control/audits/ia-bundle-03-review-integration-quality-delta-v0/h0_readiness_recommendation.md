# H0 Readiness Recommendation

Recommendation: proceed to `H0-BUNDLE-01 - Source OS registry and policy foundation`.

Reason:

IA now has a fixture-only foundation, a fail-closed bounded live-probe envelope,
and a dry-run review/quality/postmortem path. That is enough to extract the
repeatable source operating system pattern before adding more connector families.

H0 should define:

- source family registry
- source capability ladder
- source policy gate
- connector fixture/replay harness
- live-probe envelope
- source cache and evidence bridge conventions
- review queue integration conventions
- coverage ledger
- connector scorecards

This recommendation does not approve IA live access or future connectors.
