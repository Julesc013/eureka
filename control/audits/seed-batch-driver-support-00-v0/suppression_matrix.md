# Suppression Matrix

| id | summary |
| --- | --- |
| fake_driver_updater | SEO driver-updater pages are not trusted support-media evidence. |
| driver_booster_or_updater_tool | Driver booster/updater utilities are outside this metadata-only lane. |
| crack | Crack-related results are unsupported and unsafe. |
| keygen | Keygen-related results are unsupported and unsafe. |
| serial | Serial-number-seeking results are unsupported. |
| warez | Warez distribution results are unsupported. |
| torrent_only | Torrent-only records are not controlled metadata leads. |
| malware_suspicious | Suspicious driver metadata needs blocking or stronger review. |
| executable_download_when_metadata_only | Metadata-only review cannot expose executable download actions. |
| wrong_hardware_model | Hardware model mismatch can make a driver harmful or useless. |
| wrong_os_version | Driver OS-version mismatch must not be presented as compatible. |
| wrong_architecture | x86/x64 or architecture mismatch needs review before promotion. |
| wrong_vendor | Vendor mismatch is not a useful driver/support lead. |
| unrelated_modern_driver | Modern drivers frequently do not support legacy target systems. |
| web_installer_when_offline_requested | Offline/support-media queries should not be satisfied by web stubs. |
| unsupported_repack | Repacked driver bundles are not review-safe without stronger provenance. |
| generic_search_result | Generic search hits are not sufficient review evidence. |
| source_only_mention | A source-only mention is not a driver/support-media candidate by itself. |
| duplicate | Duplicate metadata should collapse into review clusters. |
| low_metadata_match | Weak title-only matches need stronger metadata before promotion. |
| unsafe_or_blocked | Unsafe or blocked driver-search results cannot be promoted. |
