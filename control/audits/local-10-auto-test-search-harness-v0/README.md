# LOCAL-10 Auto-Test And Auto-Search Harness

This audit pack records the LOCAL-10 local eval harness. The harness runs fixed
localhost suites against the local service and workbench, records latency smoke
values, and checks read-only and worker safety posture.

It is not production readiness, public launch readiness, live source search, a
source probe, extraction, model/provider execution, LAN enablement, or
deployment.
