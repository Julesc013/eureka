# Auto-Search Suite

The built-in query suite is fixed for LOCAL-10:

- `sampleproject`
- `definitely-not-present-local-10`
- `visual studio 2008 express`
- `old printer driver windows xp`
- `mac os 9 utility`
- `query with <unsafe> chars`
- an overlong query generated in code

All queries check only the local reviewed public index. Missing-result queries
also check the local absence route.
