# Workbench Console Matrix

The DOMAIN console foundation defines:

- `/domain`
- `/domain/{domain_id}`
- `DomainListView`
- `DomainPackView`
- `DomainQueryHintView`
- `DomainSourcePreferenceView`
- `DomainResultExpectationView`
- `DomainActionPostureView`
- `DomainSynCoverageView`

All projections are read-only. Operator workbench receives full detail; public
web and native desktop read-only projections receive summaries.
