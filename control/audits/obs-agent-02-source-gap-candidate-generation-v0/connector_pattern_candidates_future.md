# Connector Pattern Candidates Future

These are future connector-pattern review candidates only. No connector runtime is implemented or enabled.

## Strongest First Review Target

Internet Archive metadata is the strongest first connector-pattern candidate because the repo-local evidence shows:

- High priority score among source gap candidates.
- Old-platform and archive query relevance.
- Existing placeholder and recorded fixture source inventory.
- Metadata and item-file-listing shape that can be bounded before any payload retrieval is considered.

## Other Candidate Patterns

- Wayback/CDX/Memento metadata: useful for capture availability and temporal metadata after URI privacy review.
- GitHub Releases metadata: useful for release/version/source identity after repository identity review.
- Package registry metadata: useful for package/version/source metadata after package identity and lifecycle-risk review.
- Manual-only community/forum sources: not a connector pattern until permissions and evidence boundaries are reviewed.
- Broad web baseline access: policy-blocked unless a future approved API path exists.

## Boundary
