# Suppression Matrix

| id | summary |
| --- | --- |
| full_book_download_when_metadata_only | Metadata-only review must not imply a full document download or public fetch action. |
| rights_claim_missing | Metadata candidates cannot create rights-clearance claims. |
| scan_completeness_unknown | Fixture metadata does not prove that every page or insert is present. |
| ocr_quality_unknown | OCR quality is not assessed without OCR or document inspection. |
| wrong_model | Model-adjacent manuals must be reviewed before being treated as relevant. |
| wrong_manual_type | Service, user, deployment, and setup manuals are distinct evidence classes. |
| wrong_platform | Platform-specific documentation must match the queried system context. |
| wrong_version | Wrong version documentation can mislead review and public search. |
| generic_search_result | Generic search hits are not sufficient review evidence. |
| source_only_mention | A source mention without document metadata remains only a lead. |
| duplicate | Duplicate metadata should collapse into review clusters. |
| low_metadata_match | Weak title-only matches need stronger metadata before promotion. |
| unsafe_or_blocked | Blocked or unsafe source posture cannot be promoted. |
| executable_download | Executable downloads are outside this document metadata batch. |
| software_installer_result | Installer results belong to a separate software or driver/support review lane. |
| unrelated_modern_documentation | Modern documentation frequently lacks relevance to legacy document queries. |
