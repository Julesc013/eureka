# Win32 Skeleton Summary

C-BUNDLE-02 adds a Win32 ANSI read-only skeleton under `native/win/win32/`.

Added scope:

- VS6-style `Eureka.dsw` and `Eureka.dsp`
- C app entry and main window files
- read-only snapshot and relay adapters
- menu/resource placeholders
- build/test/dist boundary notes

The skeleton is build-unverified. It does not provide live access, downloads,
installs, execution, account flows, telemetry, or index mutation.
