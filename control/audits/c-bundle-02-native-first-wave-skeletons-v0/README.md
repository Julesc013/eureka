# C-BUNDLE-02 Native First-Wave Skeletons Audit

This audit records the Win32, AppKit, and Carbon read-only native skeletons.

The skeletons consume local snapshot, relay, action, and blocked-action fixture
surfaces. They do not perform live access, downloads, installs, execution,
telemetry, account flows, public relay behavior, public index mutation, master
index mutation, or truth acceptance.
