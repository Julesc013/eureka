# Source Policy Decision Items

This list is a future human/operator review queue. It is not source approval.

## Review Required

- Internet Archive metadata source family.
- Wayback/CDX/Memento metadata source family.
- GitHub Releases metadata source family.
- Package registry metadata source family.
- Manual-only forum or community source leads.

## Blocked

- Broad web scraping.
- Any source family requiring credentials, private caches, binary downloads, installer execution, live probes, or unreviewed API use.

## Decision Boundary

- A useful source lead is not evidence truth.
- A source family recommendation is not permission to crawl.
- A connector suggestion is not connector runtime.
- Source policy decisions must be recorded separately before live access is allowed.
