This audit pack records the automated clean-machine bootstrap proof for the Local Appliance.

The proof uses a filtered temp checkout/copy, an explicit local instance path, localhost service smoke, HTML workbench smoke, auto-test, auto-search, shutdown validation, and clean-state checks.
