# E2E Preview Index v0

Task: `E2E-PREVIEW-INDEX-00`

This audit records the first E2E Preview Index implementation. The work adds a
derived, status-aware, authority-preserving index over reviewed inputs,
candidate deltas, evidence summaries, source observations, and ResolutionRun
bundles.

The Preview Index is rebuildable local state. It does not create reviewed IA
truth, reviewed records, reviewed/master index mutations, public-index
mutations, snapshots, provider calls, downloads, public exposure, or license
changes.
