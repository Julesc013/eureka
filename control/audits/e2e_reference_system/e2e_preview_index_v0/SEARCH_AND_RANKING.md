# Search and Ranking

Preview search is deterministic lexical search over normalized search text,
title, summary, and refs. Authority and status influence ranking but do not
change truth posture.

Defaults:

- synthetic records excluded;
- rejected records excluded;
- superseded records excluded;
- filters are available for status, authority, source family, and run ID.

Result lanes group records into reviewed, candidates, near misses, needs,
absence/next steps, blocked/unavailable, and other.
