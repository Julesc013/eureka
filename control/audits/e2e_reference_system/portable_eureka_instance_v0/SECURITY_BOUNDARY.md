# Security Boundary

Portable v0 keeps the local reference system private:

- loopback-only service
- no public alpha enablement
- no LAN bind
- no live providers
- no downloads
- no execution
- no model calls
- no production review decisions
- no reviewed/master/public-index mutation
- no operator token persistence

Server smoke uses loopback HTTP only and is not a provider/network acquisition path.
