# Path Model

Instance precedence:

```text
--instance
EUREKA_INSTANCE
../instances/default
```

Portable roots:

```text
run/e2e-reference/runs/
db/e2e-reference/preview-index/
run/e2e-reference/eval/
run/e2e-reference/portable-instance/
logs/eureka-portable.log
tmp/e2e-reference/
exports/backups/
```

Repo root, product roots, hidden/private roots, and path traversal are rejected.
