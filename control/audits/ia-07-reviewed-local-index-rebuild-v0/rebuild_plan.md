# Rebuild Plan

The IA-07 proof builds the full local pilot path in a temporary explicit
instance:

1. IA fixture/live-preview records to source cache.
2. Source cache records to evidence candidates.
3. Evidence candidates to provisional candidates.
4. Candidates to review decisions.
5. Review decisions to promotion previews.
6. Promotion previews to reviewed local records.
7. Reviewed local index search, object, and absence proof.
