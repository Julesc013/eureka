# TSIS-00 Summary

TSIS-00 creates the foundation for Eureka's Temporal Semantic Interface System:

- semantic contracts
- renderer/skin/budget/fallback/cache-key contracts
- view contract stubs
- semantic and representation registries
- future Surface Kernel placement, with runtime implementation deferred
- no new top-level renderer/app/service/data/infra roots
- no runtime behavior change
- no launch, deployment, index mutation, source calls, downloads, OCR,
  extraction, or model calls
