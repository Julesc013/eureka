# Live Probe Envelope Report

Live-probe envelopes are modeled as dry-run or blocked records in H0-BUNDLE-02.
They do not grant permission to call a source.

Future live probes require explicit source policy approval, endpoint allowlists,
User-Agent/contact decisions, rate/timeout/retry/cache policy, kill switch,
output path policy, review gates, fixture replay, dry-run preflight, and
post-run audit evidence.
