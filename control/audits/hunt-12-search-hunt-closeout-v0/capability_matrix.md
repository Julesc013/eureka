# Capability Matrix

HUNT-12 classifies these Search Hunt capabilities as implemented and tested:

- hunt track plan
- Search Hunt Session runtime
- hunt UI state
- commands and steering
- exhaustion reports
- SearchNeed runtime and hunt-to-need creation
- SearchNeed-to-WorkUnit creation
- background hunt runner over deterministic workers
- CLI/API/HTML workflow smoke
- agent research task contract with providers disabled
- deterministic replay
- AI escalation gate disabled by default

Proof level is repo-local inventory, audit pack, focused validator, and smoke
evidence. These capabilities do not authorize source probes, extraction, model
providers, downloads, deployment, or direct truth/index acceptance.
