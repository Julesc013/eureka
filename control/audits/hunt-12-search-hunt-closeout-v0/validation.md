# Validation

Required HUNT-12 validation lanes:

- JSON parsing for all closeout inventories and the audit report
- closeout audit script
- handoff preparation script
- promotion-review preparation script
- capability summarizer
- closeout validator
- focused HUNT-12 operation tests
- generated artifact cleanliness
- architecture boundaries

Validation is reported honestly as pass_with_warnings when old queue-sensitive
validators or broad test timeouts appear.
