# Future Track Gate

Future tracks must use the Search Hunt spine unless an explicit reviewed task
creates an exception.

- SYN uses HUNT and Local Appliance structures for query pressure.
- F0 creates extraction tasks as WorkUnits where applicable.
- G consumes exhaustion, near-miss, and absence state.
- H source expansion starts from policy-gated source-probe WorkUnits.
- K AI assist uses the AI escalation gate and remains candidate-only.

No future track may bypass HUNT, WorkUnit, review, and index paths silently.
