# Query Taxonomy

SYN-00 defines six query families:

- `local_reviewed_lookup`
- `hunt_absence_pressure`
- `play_demo_need`
- `ia_metadata_candidate`
- `policy_blocked_adversarial`
- `privacy_rejection_adversarial`

The required split labels are `demo`, `hard`, and `adversarial`.

Synthetic cases are fixtures. They are not user demand, accepted evidence, accepted results, or public search quality proof.
