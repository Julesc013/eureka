# H1 Source Pack Summary

H1-BUNDLE-01 adds a draft source-pack manifest and aggregate policy pack for seven metadata-first sources:

- Wayback / CDX / Memento
- GitHub Releases
- PyPI
- npm Registry
- Software Heritage
- Repology
- OSV

The source pack is `draft_only`. It is not imported, submitted, accepted, or used to mutate any public or master index.

No live access is enabled.
