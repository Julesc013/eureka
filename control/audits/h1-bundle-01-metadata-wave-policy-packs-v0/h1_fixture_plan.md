# H1 Fixture Plan

H1-BUNDLE-02 should add committed fixtures for each source:

- minimal metadata record
- typical result record
- policy-blocked record
- malformed or partial record
- pagination or cursor shape where relevant
- no-live-call evidence
- no downloaded payloads
- no credentials, cookies, tokens, or private files

This bundle does not add live probes or fixture normalizers. It records the plan and boundary only.
