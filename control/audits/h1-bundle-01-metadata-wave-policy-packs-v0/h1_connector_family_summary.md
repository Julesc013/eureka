# H1 Connector Family Summary

H1 maps source records to existing H0 connector families:

- `warc_cdx`: Wayback / CDX / Memento
- `api_json`: GitHub Releases, Software Heritage, Repology, OSV
- `package_registry`: PyPI, npm Registry

Ambiguous mappings are recorded with alternate connector families where useful. The mappings are descriptive only and do not enable connector runtime or live access.
