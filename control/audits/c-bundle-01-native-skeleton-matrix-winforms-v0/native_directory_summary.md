# Native Directory Summary

C-BUNDLE-01 adds the governed `native/` skeleton using API and toolchain names:

- `native/mac/carbon`
- `native/mac/appkit`
- `native/mac/swiftui`
- `native/win/win16`
- `native/win/win32`
- `native/win/winforms`
- `native/win/winui`
- `native/lib/c89`
- `native/lib/objc`
- `native/lib/dotnet`
- `native/matrix`

Support state remains in matrix files. The skeleton does not create CodeWarrior, VS6, Xcode, SwiftUI, Win16, or WinUI project files.
