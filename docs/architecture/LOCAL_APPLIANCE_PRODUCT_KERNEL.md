# Local Appliance Product Kernel

The Local Appliance is Eureka's mandatory product proof surface after LOCAL-14.
Future product-scoped work must be runnable, inspectable, locally testable, and
audited through this kernel where the feature touches local runtime behavior.

The kernel includes explicit instance roots, runtime composition, reviewed-index
HTTP service routes, HTML workbench pages, WorkUnits, local review/rebuild,
deterministic workers, auto-test/search, LAN read-only safety, and clean-machine
bootstrap proof.

This is not a production readiness claim, public launch claim, hosted service,
or deployment. It is the local execution spine for future HUNT, SYN, F0, and
other product tracks.
