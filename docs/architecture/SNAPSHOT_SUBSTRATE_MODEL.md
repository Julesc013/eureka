# Snapshot Substrate Model

The D snapshot substrate packages explicit fixture/local records into a bounded offline bundle.

The model has five parts:

- Envelope: outer identity, scope, refs, no-claims, and boundaries.
- Manifest: deterministic list of normalized records and summaries.
- Records: renderable posture-preserving search/object/source/need/action entries.
- Verification: local fixity and envelope checks.
- Consumer/reporting: offline load reports that do not activate live behavior.

The substrate deliberately sits below hosting and relay work. It proves that canonical local meanings can be moved through offline JSON/text/HTML/tree projections without depending on a backend.
