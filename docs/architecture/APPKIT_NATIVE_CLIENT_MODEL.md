# AppKit Native Client Model

The AppKit lane is an Objective-C skeleton for an Xcode 9.x style host.

It provides an app delegate, main window controller, read-only search view, and
snapshot/relay adapters. The project directory is a documented placeholder
instead of a fabricated `.xcodeproj` build graph.

The AppKit client remains a local fixture reader. It has no source probing,
network dependency, downloads, installs, execution, credentials, telemetry, or
index mutation.
