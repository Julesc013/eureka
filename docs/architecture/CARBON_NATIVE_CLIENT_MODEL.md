# Carbon Native Client Model

The Carbon lane is a conservative C skeleton for a future CodeWarrior Pro 8/9
host.

C-BUNDLE-02 documents the intended `Eureka.mcp` project instead of fabricating a
binary CodeWarrior project file. The source tree includes app, window, snapshot,
and relay adapter placeholders for future manual project creation.

The Carbon client remains read-only and fixture-oriented. Build evidence is
manual and future.
