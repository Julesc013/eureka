# Snapshot Review Batch Apply Projection

The review-batch apply section summarizes the already completed temp explicit
apply proof. Snapshot refresh uses it as evidence for projection only.

The section records eligible applies, reviewed record deltas, reviewed known
needs, reviewed bounded absences, and non-applied candidates. It also records
that the apply was temp-only and did not mutate an operator instance, public
index, master index, or reviewed index.

Snapshot refresh must not reinterpret apply evidence as artifact verification,
download availability, malware-clean status, compatibility proof, rights
clearance, scan completeness, or OCR quality.
