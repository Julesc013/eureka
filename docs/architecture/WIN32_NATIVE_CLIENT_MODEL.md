# Win32 Native Client Model

The Win32 lane is a Visual C++ 6.0 style ANSI client skeleton.

It uses conservative C and Win32 ANSI calls to show placeholder panes for search
results, object/source summaries, relay status, blocked actions, and
diagnostics. It consumes local fixture text through native adapters and does not
own resolution, source access, or truth acceptance.

The VS6 project files are build-unverified in C-BUNDLE-02. Manual smoke evidence
is required before any future build-verified claim.
