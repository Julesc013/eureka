# Review Live Metadata Candidates

`REVIEW-LIVE-METADATA-CANDIDATES-00` reviews already observed, redacted Internet Archive metadata candidates.

The review output can preview a reviewed metadata record or reviewed source lead, but it does not verify downloadable artifacts. Metadata is treated as source evidence only.

Boundaries:

- no new live source calls
- no raw live response commit
- no downloads or extraction
- no malware-clean or rights-clearance claim
- no accepted truth
- no reviewed, master, or public index mutation

Promotion previews are handoffs. A later local apply gate is required before any reviewed local record can be applied, and a later snapshot refresh gate is required before projections change.
