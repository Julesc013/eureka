# Reviewed Metadata Record Snapshot Section

The reviewed metadata record section contains metadata-only records created by the temp local-apply gate.

Allowed claim:

- metadata record was reviewed under local policy using redacted source observations and review evidence

Forbidden claims:

- verified download
- safe installer
- extracted file
- malware clean
- rights cleared
- production-quality artifact

These records are displayed as limited reviewed metadata/source-lead material, distinct from verified artifact records.
