# G0 Identity And Near-Miss Model

G0 identity grouping is provisional. It can suggest same-object, same-version,
same-release, representation, mirror, duplicate, parent-bundle, member, and
related-but-distinct candidate groups for review.

No G0 packet performs a destructive merge or changes canonical identity. Source
specific locators remain visible so reviewers can inspect conflicts and
alternative representations. Parent bundle and member records stay distinct.

Near misses must explain why a record is not exact, such as wrong platform,
wrong version, parent-bundle-only visibility, member-only visibility, or a
related but distinct trail. Near misses are surfaced as review aids, not hidden
suppression.
