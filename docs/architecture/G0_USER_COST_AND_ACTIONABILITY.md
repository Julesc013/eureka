# G0 User Cost And Actionability

User-cost scoring estimates the amount of work a user or operator would need
before a result is useful. It is an estimate, not an availability,
installability, safety, rights, or truth claim.

Classes include direct reviewed result, provisional candidate needs review,
source-cache hit needs evidence, parent bundle known member unknown, member path
known, file manifest only, mention only, known absence, policy blocked,
deferred extraction needed, source probe needed, and manual research needed.

Actions remain blocked by policy unless a future reviewed task enables them.
G0 may recommend future WorkUnit seed types, but it does not create runtime
WorkUnits or mutate queues.
