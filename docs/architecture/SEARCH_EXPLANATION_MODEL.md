# Search Explanation Model

Track G adds an offline explanation layer over fixture/local records. It reads explicit input bundles and produces result explanations, near misses, known absence records, and search-gap explanations.

The model explains inclusion and gaps without changing ranking or public search behavior. Explanation records are evidence-linked reasoning artifacts, not authority.

Inputs can include SearchNeed refs, candidate records, source-cache records, evidence records, and extraction search gaps from F-BUNDLE-02.
