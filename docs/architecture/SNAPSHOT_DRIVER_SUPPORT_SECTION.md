# Snapshot Driver/Support Section

The driver/support snapshot section contains review-only metadata candidates
for `driver_support_media`.

The section requires these non-claims:

- `download_performed: false`
- `file_fetch_performed: false`
- `install_execution_enabled: false`
- `malware_clean_claim_created: false`
- `compatibility_guarantee_created: false`
- `rights_clearance_claim_created: false`
- `accepted_truth: false`

The section can support internal review and public search candidate displays.
It must not present a candidate as a verified driver package, safe installer,
compatible hardware/OS package, malware-clean file, rights-cleared artifact, or
reviewed artifact.
