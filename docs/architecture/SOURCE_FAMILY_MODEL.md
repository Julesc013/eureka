# Source Family Model

Source families group sources by governance shape rather than domain name.

H0 source families include archive metadata, web archive traces, package
registries, OS package archives, code/source/release hosts, vendor update and
driver catalogs, library/cultural/research catalogs, manuals/docs/standards,
media catalogs, games/emulation/software identity, storefront/app-store
metadata, retro community archives, local/private user-supplied sources,
restricted manifest-only sources, and source discovery scorecards.

Each family defines preferred adapter families, default depth, typical trust
lane, risk posture, live-access posture, download posture, review requirements,
and no-goals.

Families make future H1 expansion modular and reviewable.
