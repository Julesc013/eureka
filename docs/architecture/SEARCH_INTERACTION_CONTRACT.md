# Search Interaction Contract

Search is an interactive resolution run, not just a lookup. Full-sentence natural-language queries are first-class inputs. The system compiles each raw query into a visible interpretation, then runs local and source-backed lanes as policy allows.

The user or operator can refine, correct, pause, resume, deepen, narrow, broaden, reject, accept for review, inspect, export, save, and watch the need. Partial results are valid outputs. Absence and uncertainty are valid outputs.

Candidate does not mean truth. Evidence candidate does not mean accepted evidence. Reviewed record does not mean master/public truth unless it is promoted through the correct layer.

AI may later assist with query suggestions or research, but AI output remains candidate material only and is never truth authority. Search Interaction does not enable source probes, extraction, downloads, deployment, public fanout, or model calls by itself.
