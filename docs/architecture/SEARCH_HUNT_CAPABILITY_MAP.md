# Search Hunt Capability Map

HUNT-00 through HUNT-11 establish these capabilities:

- track plan and future gate
- persisted Search Hunt Sessions
- Local Workbench hunt visibility
- pause, resume, cancel, and steering commands
- local/current-index exhaustion reports
- SearchNeed runtime and hunt-to-need creation
- SearchNeed-to-WorkUnit creation without execution
- background runner for safe deterministic local workers
- end-to-end CLI/API/HTML workflow smoke
- agent research task contract with providers disabled
- deterministic hunt replay
- disabled-by-default AI escalation gate

The closeout matrix records each capability with proof level, validator, smoke
coverage, and limitations. All capabilities are implemented and tested at the
local deterministic proof level.
