# Limited Reviewed Record Model

A limited reviewed record is a local reviewed claim with a narrow scope.

For this task the supported scopes are:

- `metadata_identity_lead_only`
- `source_lead_only`
- `known_need_only`
- `bounded_absence_only`

These records can improve corpus usefulness and snapshot projections, but they
do not prove that a file was downloaded, extracted, safe, installable,
compatible, rights-cleared, OCR-verified, or scan-complete.

Public UX and API projections must keep limited reviewed records visually and
semantically distinct from verified artifacts.
