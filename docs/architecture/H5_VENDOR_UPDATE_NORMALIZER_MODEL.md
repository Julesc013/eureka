# H5 Vendor Update Normalizer Model

H5 normalizers share a fixture loader, common candidate builders, and source-specific wrappers. Runtime modules use the standard library only and do not fetch catalogs or artifacts.

This prepares H5-BUNDLE-03 by proving fixture parsing and boundary behavior before any separately approved metadata-only live probe.
