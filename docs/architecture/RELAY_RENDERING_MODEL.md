# Relay Rendering Model

Relay rendering is a projection of already available snapshot data.

Supported profiles are:

- `text`
- `lite_html`
- `file_tree`
- `json_manifest`
- `terminal`
- `native_fixture_json`

Every renderer preserves identity, source posture, evidence posture, rights
posture, risk posture, action posture, and limitations/no-claims. Renderers do
not fetch external resources and do not activate public routes.
