# H13 Local Private Review Integration Model

The H13 review integration model keeps fixture replay records, blocked boundary dry-run evidence, review seeds, candidate promotion previews, coverage previews, scorecard updates, and source pack previews separated from accepted source/evidence/candidate truth. Source OS boundaries remain no-access and no-mutation.

## Validation

Run `python scripts/validate_h13_local_private_review_quality_audit.py` plus the task validation lane. H13 review artifacts are audit evidence only.
