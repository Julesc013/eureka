# SNAPSHOT-REFRESH-03

`SNAPSHOT-REFRESH-03` is a projection-only refresh after the temp local-apply proof for live metadata review previews.

It packages one limited reviewed metadata record and two limited reviewed source leads into snapshot sections. These records improve internal review and demo usefulness, but they are not verified artifacts, downloads, extracted files, malware-clean assertions, or rights-clearance assertions.

The refresh does not mutate operator instances, reviewed indexes, master indexes, public indexes, `site/dist`, or `data/public_index`. Public alpha reassessment remains a separate task.

Core sections:

- existing reviewed records
- reviewed metadata records from local apply
- reviewed source leads from local apply
- still-review-only fixture and live metadata candidates
- local apply summary
- review queue, needs, and absences
- relay and public search view-model projections
- public alpha reassessment input
