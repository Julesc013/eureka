# Eureka Node

A Eureka Node is a future governed worker identity. It can represent a local private worker, pack builder, dry-run planner, community worker, institutional worker, or hosted worker. TRACK-B-01 defines identity and boundaries only.

## What A Node Is

- A declared worker identity with mode, status, capabilities, limits, input/output boundaries, and review policy.
- A future place to connect WorkUnits, packs, observation candidates, source leads, and reviewable evidence drafts.
- A contract for what the node may prepare or propose.

## What A Node Is Not

- Not a runtime.
- Not a crawler, scraper, downloader, installer, hosted backend, account system, telemetry source, model caller, or source connector.
- Not a path to public truth or master-index mutation.

## Relationship To OBS

OBS-REPLAN-01 allows agents to prepare review-gated observation candidates and source leads. Node manifests define the future worker identity that may prepare those candidates under explicit policy. Manual Observation Batch 0 remains the gold-standard human calibration lane.

## Local State

Current node examples do not create local state. Future local state must be ignored by Git, export-reviewed, resettable, and private-data-safe.

## Review

Human review is required for public export, evidence acceptance, candidate promotion, source policy, network access, and any master-index mutation request. Current manifests deny master-index mutation entirely; the master index remains outside node authority.

## Deferred

Node policy, WorkUnit contracts, node runtime, local state implementation, source access approval, and hosted workers are deferred.
