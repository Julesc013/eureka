# Safe Action Model

J0 separates descriptive action manifests from risky actions.

Safe current actions:

- view metadata
- inspect local records
- compare explicit refs while preserving conflicts
- cite source/evidence posture
- export manifest previews
- describe acquisition paths
- describe preservation posture
- explain blocked actions

Risky actions are future-only: download, mirror, install, execute, emulate, submit, and import. They require future policy, review gates, user confirmation, risk review, rights review, and action audit before any implementation.

No public search behavior changes in J0. No public index or master index is mutated.
