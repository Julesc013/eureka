# Extraction Tier Model

Current tiers:

- Tier 0: outer metadata for a fixture container.
- Tier 1: member listing with safety flags.
- Tier 2: bounded manifest-candidate extraction.

Future tiers remain disabled:

- Tier 3: selective text preview.
- Tier 4: recursive deep extraction.
- Tier 5: on-demand deepening.

Future tiers require separate policy, safety review, and validation. F-BUNDLE-01 does not enable recursive extraction.
