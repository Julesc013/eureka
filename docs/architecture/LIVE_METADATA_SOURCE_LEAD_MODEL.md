# Live Metadata Source Lead Model

A live metadata source lead is a reviewed pointer to useful source metadata. It
is not a verified artifact and it is not an install/download action.

The source lead action posture allows metadata inspection and follow-up review.
It blocks download, extraction, execution, install, safety claims, and rights
claims.

Source leads are useful for corpus-building and later review work, but they do
not by themselves make the public alpha launch-ready.
