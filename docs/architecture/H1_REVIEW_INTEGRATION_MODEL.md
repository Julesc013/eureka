# H1 Review Integration Model

The H1 review model is a wave-level rehearsal:

1. Fixture replay outputs provide normalized metadata and candidate previews.
2. Live-probe outputs, when blocked, provide policy-gate evidence.
3. Review integration turns those explicit inputs into review seed previews.
4. Quality delta counts bounded operational readiness and gaps.
5. Postmortem and audit route the project to extraction sandbox work or remediation.

The model preserves Source OS boundaries: sources are not connectors, connector output is not truth, capability is not permission, and review seeds are not review decisions.
