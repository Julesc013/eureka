# Search Hunt Product Spine

Search Hunt is Eureka's local investigation spine. It organizes difficult
searches through durable records rather than direct truth claims.

The spine is:

1. reviewed local index search
2. Search Hunt Session
3. command and steering state
4. exhaustion report
5. SearchNeed
6. WorkUnits
7. deterministic local workers where allowed
8. review/evidence/index path when future evidence exists

HUNT does not execute source probes, extraction, browser work, AI providers,
downloads, install actions, deployment, or master-index mutation. It also does
not prove global absence, accept evidence, clear rights, or clear malware
safety.

Future SYN, F0, G, H, and K work must use this spine where applicable. Any
exception needs an explicit reviewed task.
