# Snapshot Manuals/Scans Section

The manuals/scans snapshot section contains review-only metadata candidates for
`manuals_docs_scans`.

The section requires these non-claims:

- `download_performed: false`
- `file_fetch_performed: false`
- `ocr_performed: false`
- `rights_clearance_claim_created: false`
- `scan_completeness_claim_created: false`
- `ocr_quality_claim_created: false`
- `accepted_truth: false`

The section can support internal review and public search candidate displays.
It must not present a candidate as a downloaded manual, OCR transcript, complete
scan, rights-cleared document, or reviewed artifact.
