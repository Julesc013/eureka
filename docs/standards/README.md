# Standards Docs

This directory contains standards that support contracts, evidence handling,
source identifiers, privacy boundaries, and shared schema discipline.

## Docs

- [Identifier Policy](IDENTIFIER_POLICY.md)
- [Privacy And Shared Evidence](PRIVACY_AND_SHARED_EVIDENCE.md)

Standards should be updated with the contracts, validators, and tests that rely
on them. Do not use standards prose to bypass review gates or claim implemented
runtime behavior.
