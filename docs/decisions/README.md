# Decision Docs

This directory contains focused ADR-style decisions. The large historical
decision ledger remains [../DECISIONS.md](../DECISIONS.md).

## Docs

- [Eureka Track Order](ADR-eureka-track-order.md)

Decision docs should name what was accepted, what remains deferred, and what
evidence or validation supports the decision. They should not imply deployment,
public launch, production readiness, or ungated runtime behavior.
