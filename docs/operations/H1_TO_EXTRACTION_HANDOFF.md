# H1 To Extraction Handoff

H1 prepares metadata source governance and fixture-equivalent connector outputs. F-BUNDLE-01 should use those outputs to build an extraction sandbox for Tier 0-2 fixture extraction.

The handoff does not carry live-source approval. H1 live probes remain blocked until committed source-specific approvals exist. F extraction should stay fixture-first, no-download by default, and review-gated before any public or master-index use.
