# Public Alpha Abuse And Takedown

The public alpha is read-only, snapshot-backed, and reviewed-index-only. It has
no public mutation, no accounts, no uploads, no public source submission, no
downloads, and no extraction.

Before any public launch, the operator must provide:

- An abuse contact.
- A takedown contact or queue.
- A review path for disputed records, source summaries, evidence summaries,
  absence language, and known-need pages.
- A response procedure for privacy or rights concerns.
- A way to roll back or suppress a problematic snapshot entry in a future
  reviewed publication task.

Absence pages must mean "not found in the current reviewed snapshot." They must
not claim that an artifact does not exist.
