# Snapshot Verification Policy

Snapshot verification is local and offline.

It may confirm that a manifest is structurally valid, records carry required posture fields, SHA-256 fixity is deterministic, unsigned or placeholder signature envelopes are represented honestly, and render outputs preserve required semantic fields.

It must not claim source authenticity, rights clearance, malware safety, verified installability, compatibility certification, production readiness, public truth, public index mutation, or master index mutation.
