# H1 Metadata Wave No Live Call Policy

H1-BUNDLE-01 does not enable live source access.

The no-live-call boundary is explicit:

- no network calls
- no API calls
- no endpoint probing
- no downloads
- no scraping or crawling
- no source sync
- no live connector runtime
- no public-query fanout
- no hosted behavior
- no model, provider, or browser automation calls

Source records, policy packs, coverage previews, and scorecard previews are descriptive planning artifacts only. They are not source observations, accepted evidence, accepted candidates, public records, source-cache writes, or pack imports.

Future fixture/runtime work must run through a new reviewed bundle and must preserve the same closed-by-default posture until a specific approval gate opens.
