# Hunt Replay Boundaries

Allowed:

- replay fixture generation
- replay result storage
- local deterministic workflow records
- safe deterministic worker transitions
- expected-vs-actual replay diffs

Forbidden:

- source probes
- extraction
- AI/model/provider calls
- browser research
- artifact acquisition
- artifact launch
- source sync
- LAN mutation
- master-index mutation
- site output writes
- deployment
- production or public launch readiness claims
