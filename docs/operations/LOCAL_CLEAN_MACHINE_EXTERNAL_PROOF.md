# LOCAL Clean-Machine External Proof

Actual second-machine proof is optional for LOCAL-13 and must be recorded honestly.

If performed, record:

- client device type
- operating system family if useful
- commands run
- routes checked
- mutation blocks checked
- timestamp
- redacted private network details

Do not record secrets, operator tokens, raw private topology, public deployment claims, production readiness claims, or public launch readiness claims.
