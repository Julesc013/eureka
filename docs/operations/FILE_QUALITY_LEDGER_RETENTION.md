# File Quality Ledger Retention

The file-quality ledger is generated by:

```powershell
py -3 .aide/scripts/aide_lite.py quality ledger
```

The retained shape is reviewable and deterministic:

- `.aide/reports/file-quality-ledger.json` is a compact summary and shard index.
- `.aide/reports/file-quality-ledger/index.json` mirrors the compact index.
- `.aide/reports/file-quality-ledger/shards/*.json` contains sorted record
  shards with stable names.
- `.aide/reports/file-quality-ledger/README.md` explains the shard set.

The summary preserves record count, warning counts, fail count, source
intelligence references, shard sizes, shard hashes, and the regeneration command.
The shards preserve per-file advisory records without placing one oversized JSON
file in Git.

The ledger remains advisory-only. It does not delete files, rewrite product
behavior, certify product quality, or make launch claims.
