# H6 Web Archive Fixture No-Live-Call Policy

H6-BUNDLE-02 is fixture-runtime work only. It normalizes committed synthetic or repo-local web archive, news, event, dead-link, public-document, media, and transcript metadata into candidate records and previews.

It is not live access, CDX/Memento lookup, WARC/WACZ fetch, archived page fetch, media or transcript download, public document fetch, scraping, crawling, browser automation, bypass, source sync, evidence acceptance, or public truth.

Outputs remain normalized records, candidate identities, source-cache previews, evidence previews, and replay reports. Review is required before any persistence, evidence acceptance, public index use, or later live-probe approval.

Validation: `python scripts/validate_h6_web_archive_news_event_fixture_runtime.py`.
