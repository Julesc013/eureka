# H1 Metadata Wave Quality Delta

Quality delta is a measurement of H1 audit readiness, not product quality. Allowed metrics include source count, fixture source count, blocked source count, normalized record count, candidate preview counts, review seed count, coverage preview count, scorecard update count, blocker count, warning count, and known gap count.

Forbidden claims include production search quality, external superiority, exhaustive coverage, rights clearance, malware safety, verified installability, and future connector auto-approval.
