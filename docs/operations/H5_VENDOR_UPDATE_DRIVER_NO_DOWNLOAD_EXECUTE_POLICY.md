# H5 Vendor Update Driver No-Download Execute Policy

H5-BUNDLE-01 forbids EXE, MSI, MSU, CAB, DMG, PKG, ZIP, TAR, driver package, firmware image, BIOS/UEFI image, runtime redistributable, installer, update package, checksum, signature, SBOM, and binary downloads.

It also forbids vendor tool invocation, package manager invocation, installer execution, artifact execution, emulator launch, and firmware flashing. Metadata references remain candidates only and do not grant action permission.
