# H13 Local Private Boundary Dry Run Private Data Policy

H13 boundary dry-runs block unrestricted paths, local file contents, credentials, cookies, tokens, sessions, receipts, license keys, entitlements, account data, private URLs, CAS blobs, exported packs, imported packs, private payloads, and publication outputs.

## Validation

Run `python scripts/validate_h13_local_private_boundary_dry_run.py` and the H13 boundary dry-run script checks. Outputs remain candidates/previews only and prepare H13-BUNDLE-04 review integration.
