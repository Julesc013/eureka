# Local Workbench Non-Claims

Every LOCAL-06 workbench page must be clear about local scope and local limitations.

## Required Wording Classes

- local only
- current index only
- reviewed local projection
- candidate or reviewed state
- limitations visible
- warnings visible

## Forbidden Claims

Workbench pages must not claim:

- production readiness
- public launch readiness
- global completeness
- exhaustive coverage
- legal approval
- rights clearance
- malware safety
- installability certification
- source truth acceptance
- evidence truth acceptance
- master index mutation
- deployment

## Absence Semantics

Absence means that the checked local reviewed public index did not return a matching result for the submitted query. It is not proof the artifact does not exist, and it does not imply that live sources, connectors, source probes, extraction, Search Hunt Sessions, or semantic search have been checked.
