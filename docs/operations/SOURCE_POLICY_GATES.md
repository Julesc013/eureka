# Source Policy Gates

No future source live access should proceed without the full gate bundle:

- source policy approval
- endpoint allowlist
- User-Agent/contact decision
- rate limit
- timeout
- retry budget
- cache TTL
- kill switch
- output path policy
- privacy/risk review
- rights posture
- review gates
- fixture replay
- dry-run preflight
- post-run audit

H0-BUNDLE-01 records the gate model only. It does not approve any new live
source calls.
