# Source Expansion No Live Call Policy

H0-BUNDLE-01 does not enable live source calls.

Source registry entries are descriptive and policy-gated. New source records do
not grant permission. Future H0-BUNDLE-02 or H1 tasks must explicitly approve
fixture behavior or live behavior.

Forbidden in H0-BUNDLE-01:

- live source calls
- external API calls
- network calls
- live probes
- source sync
- downloads
- scraping or crawling
- public query fanout
- public-index mutation
- master-index mutation
- evidence, candidate, source, pack, or public-truth acceptance
