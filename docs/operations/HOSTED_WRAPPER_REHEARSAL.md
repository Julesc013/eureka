# Hosted Wrapper Rehearsal

Run hosted wrapper rehearsal with local fixtures only. The scripts write no files by default and refuse provider, secret, public index, runtime-generated, contracts-generated, and site/dist output roots.

Validation commands are listed in the E-BUNDLE-02 audit pack. All examples preserve no deployment, no provider call, no DNS change, no site/dist mutation, no live fanout, and no production claim.
