# Local MVP Next Wave Selection

The next-wave router evaluates H2, H3, J1, K, L, deployment approval, and remediation. H2 is the default recommendation when prior MVP and deployment-planning evidence has no blockers.

H3 waits for H2 package-registry patterns. J1 waits for explicit risky-action policy. K waits for typed semantic/AI no-truth gates. L waits for wider-client planning. Deployment waits for future explicit operator approval.
