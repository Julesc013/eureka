# Search Hunt UI Non-Claims

The Search Hunt UI must not claim:

- a hunt is truth
- local absence is global proof
- a candidate is verified
- rights or malware safety are cleared
- exhaustive search was performed
- AI verified a result
- production or public launch readiness

The UI may say:

- reviewed local index first
- local/current-index absence
- unchecked layers visible
- actions deferred
- limitations and warnings visible
