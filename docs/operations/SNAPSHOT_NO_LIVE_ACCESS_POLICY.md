# Snapshot No Live Access Policy

D-BUNDLE-01 does not enable live access.

Snapshot runtime and scripts must not call networks, APIs, models, providers, browsers, external sources, source sync, live probes, relay servers, hosting, downloads, mirroring, installers, execution, emulation, uploads, accounts, or telemetry.

Future relay work must consume snapshot outputs through a separate reviewed task. D-BUNDLE-01 only produces offline fixture projections.
