# Local Review Non-Claims

Every LOCAL-08 review and rebuild surface must preserve these non-claims:

- A local review decision is local operator state, not global proof.
- A reviewed index record is a local reviewed projection.
- Rebuild does not create legal approval, rights clearance, malware safety, or
  installability certification.
- Rebuild does not prove exhaustive source coverage.
- Rebuild does not mutate a master index.
- Rebuild does not write `site/dist`.
- LOCAL-08 does not enable LAN or deployment.
- LOCAL-08 does not execute queued work, source probes, extraction, or model
  calls.
