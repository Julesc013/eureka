# IA Metadata Quality Delta

IA metadata quality delta is a local audit measurement for review integration,
not a production search claim.

Allowed metrics:

- candidate count delta
- source-cache record count delta
- evidence candidate count delta
- review entry count delta
- fixture-only result presence delta
- fixture-only near-match delta
- known gap delta
- blocked reason count
- connector error count

Forbidden claims:

- external search superiority
- exhaustive global coverage
- production search quality
- rights clearance
- malware safety
- verified installability

For IA-BUNDLE-03, the delta is expected to show useful local review artifacts
while preserving the blocker that no approved live IA probe has completed.
