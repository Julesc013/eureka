# IA Metadata Non-Claims

IA-00 does not claim that Eureka can use Internet Archive live metadata today.
It only closes the policy boundary for a future metadata-only local pilot.

## Not Claimed

- no production readiness
- no public launch readiness
- no live source readiness
- no extraction readiness
- no AI/model readiness
- no download or preservation action readiness
- no source-cache write readiness
- no evidence ledger readiness
- no reviewed-index integration readiness

## Metadata Is Not Truth

Future IA metadata can be recorded only as source observation material. It does
not prove:

- artifact identity
- rights status
- malware or safety status
- compatibility
- availability of file bytes
- provenance certainty
- source trust

Those claims require later evidence candidate generation, review, and accepted
reviewed-index promotion.

No IA metadata field becomes accepted truth without review.
