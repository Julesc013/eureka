# H6 Web Archive News Event No Fetch Crawl Policy

H6 forbids CDX/CDXJ network fetches, Memento lookups, WARC/WACZ downloads, archived page downloads, live page fetches, media downloads, transcript downloads, newspaper page downloads, public document downloads, bulk index fetches, crawl execution, browser automation, captcha/paywall/auth bypass, robots bypass, account/session use, scraping output, and sensitive-source direct access.

Validation: `python scripts/validate_h6_web_archive_news_event_policy_packs.py`.
