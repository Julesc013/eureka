# R0 Remaining Limitations

R0 closes the recovery runway, but not every future track.

Remaining limitations:

- Contract taxonomy still has unresolved items and compatibility shims.
- Legacy H-series architecture leakage remains allowlisted, not remediated.
- The one-source live test proves only one metadata source and one package.
- The reviewed public index is local SQLite state, not a hosted public index.
- Local review acceptance is not global truth, rights clearance, malware safety, installability, or production readiness.
- F0 extraction work has not started.

These limitations are explicit so future tasks do not treat scaffold evidence as product maturity.
