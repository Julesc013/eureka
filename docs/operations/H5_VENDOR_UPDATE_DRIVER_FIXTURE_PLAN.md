# H5 Vendor Update Driver Fixture Plan

H5-BUNDLE-02 should add committed synthetic or repo-local fixtures for each H5 source. Required shapes include minimal vendor/update metadata, typical support/download metadata, driver metadata where applicable, firmware/update metadata where applicable, runtime redistributable metadata where applicable, device compatibility metadata where applicable, OS/architecture metadata where applicable, hash/signature metadata where applicable, release-note/changelog/advisory metadata, policy-blocked records, and malformed/partial records.

Fixtures must include no live-call evidence, downloaded payloads, firmware images, installers, vendor-tool output, credentials, package-manager output, private files, or executable artifacts.
