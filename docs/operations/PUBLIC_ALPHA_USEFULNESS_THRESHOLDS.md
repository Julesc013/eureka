# Public Alpha Usefulness Thresholds

The public alpha reassessment thresholds are conservative product-policy
estimates. They are not factual claims about final search quality.

Current launch thresholds:

- minimum reviewed records: 25
- minimum reviewed domain coverage: 3 domains
- minimum usefulness score: 0.75

Current v0 snapshot:

- reviewed records: 1
- reviewed domains: 1
- review-only candidates: 28

Current v1 live-metadata snapshot:

- reviewed records: 1
- reviewed domains: 1
- fixture candidates: 28
- live-metadata candidates: 8
- total candidates: 36

Current v2 live-metadata-review snapshot:

- reviewed records: 1
- reviewed metadata record previews: 1
- reviewed source lead previews: 2
- useful leads: 1
- needs more evidence: 2
- rejected or duplicate: 2

This means the refreshed snapshot is more useful for internal demonstration and
operator review, but it is still not launch-sufficient as a public search
engine. Review previews improve readiness but do not count as reviewed records
until an explicit local apply gate applies them and later snapshots are
refreshed.
