# Public Alpha Usefulness Thresholds

The `PUBLIC-ALPHA-REASSESS-00` thresholds are conservative product-policy
estimates. They are not factual claims about final search quality.

Current launch thresholds:

- minimum reviewed records: 25
- minimum reviewed domain coverage: 3 domains
- minimum usefulness score: 0.75

Current snapshot:

- reviewed records: 1
- reviewed domains: 1
- review-only candidates: 28

This means the refreshed snapshot is useful for internal demonstration and
operator review, but it is not launch-sufficient as a public search engine.
