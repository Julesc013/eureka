# Post F0 Foundation Plan

After F0, the recommended next task is G0: ranking, explanation, identity, and user-cost scoring foundation.

Deferred F0 work includes container-specific fixture policies, deeper archive-member tests, safe TAR review, ISO descriptor review, and future extraction WorkUnit handling. Those tasks must remain fixture-only or explicitly introduce a new reviewed policy gate.

F0 did not create truth and is not truth. It added manifest-only examples and read-only validation over committed fixtures. There were no downloads, no filesystem extraction, no execution, no source probes, no operator instance mutation, and no master/public index mutation.

Any future extraction path must keep review gates in front of evidence, reviewed records, and indexes. F0 member observations are candidates only.
