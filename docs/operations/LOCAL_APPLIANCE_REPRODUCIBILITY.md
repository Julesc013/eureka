# Local Appliance Reproducibility

The Local Appliance reproducibility gate requires:

- clean temp checkout/copy proof
- explicit instance initialization
- instance validation
- runtime status check
- localhost server smoke
- HTML workbench smoke
- auto-test and auto-search
- shutdown and clean-state checks

The proof confirms the local appliance can be reproduced from source into explicit local state. It does not certify global truth, legal approval, rights clearance, malware safety, production readiness, public launch readiness, or deployment readiness.
