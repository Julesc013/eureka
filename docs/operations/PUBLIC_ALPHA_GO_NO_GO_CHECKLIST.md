# Public Alpha Go/No-Go Checklist

This checklist answers whether the promoted read-only alpha can move to a
future deploy dry run. It is not a public launch checklist.

- Public alpha read-only foundation: pass
- Public alpha hosting readiness: pass
- Public alpha closeout: pass
- Snapshot relay: pass or accepted warnings
- External full discovery: pass
- Public routes read-only: pass
- Public API read-only: pass
- Public mutation disabled: pass
- Public live source fanout disabled: pass
- Downloads disabled: pass
- Extraction disabled: pass
- Model/provider calls disabled: pass
- Security, privacy, abuse, observability, and rollback plans: present
- Manual approval before deploy or launch: required

No-go conditions include any deployment, production-readiness claim, public
launch-readiness claim, public mutation, live source fanout, missing rollback
plan, missing privacy/abuse process, or failing external full discovery.
