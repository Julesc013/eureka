# Native No-Download And No-Execute Policy

C-BUNDLE-01 blocks all risky native actions.

Blocked capability families:

- download artifact
- mirror artifact
- install artifact
- execute artifact
- emulate artifact
- run installer
- open untrusted payload
- fetch remote URL
- source probe
- source sync

Safe alternatives are descriptive: display local snapshot fixtures, relay fixture envelopes, action manifests, blocked action reports, limitations, and no-claims.
