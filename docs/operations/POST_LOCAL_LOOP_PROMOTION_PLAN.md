# Post Local Loop Promotion Plan

After the completed local product-loop baseline is promoted to `main`, the next
recommended task is:

`SOURCE-ACTION-KERNEL-00 - Generic source action adapter model and source-family extension seam`

The purpose is to add a source-action adapter model before more source families
are implemented. Source expansion should not proceed through one-off source
scripts.

Planned sequence:

1. `SOURCE-ACTION-KERNEL-00`
2. `SOURCE-WAVE-00`
3. `SNAPSHOT-RELAY-00`
4. `PUBLIC-ALPHA-READONLY-00`

The promoted baseline remains local-first and reviewed-index focused. It does
not enable public live source fanout, downloads, extraction, deployment, or
production/public-launch claims.
