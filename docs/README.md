# Eureka Docs

This directory is the human-facing documentation entry point for Eureka. It
orients readers to the current local-first prototype, public-alpha read-only
baseline, architecture, roadmap, operating rules, and historical decision
records.

## Start Here

- [Bootstrap Status](BOOTSTRAP_STATUS.md): current maturity and non-claims.
- [Architecture](ARCHITECTURE.md): component boundaries and dependency law.
- [Repo Layout](REPO_LAYOUT.md): top-level directory ownership.
- [Roadmap](ROADMAP.md): staged next work from launch candidate through public
  alpha approval gates.
- [Vision](VISION.md): product direction and doctrine.
- [Test and Eval Lanes](operations/TEST_AND_EVAL_LANES.md): verification
  discipline, including full-discovery handoff rules.

## High-Traffic Subdirectories

- [architecture/](architecture/README.md): accepted product and system models.
- [operations/](operations/README.md): runbooks, safety policies, gates, and
  evidence procedures.
- [reference/](reference/README.md): contracts, APIs, schemas, and stable
  reference material.
- [roadmap/](roadmap/README.md): detailed staged planning.
- [vision/](vision/README.md): thesis, product promise, and doctrine.
- [evals/](evals/README.md): benchmark design and evaluation guidance.
- [standards/](standards/README.md): project standards and schema guidance.
- [decisions/](decisions/README.md): focused ADR-style decisions.

## Historical Records

- [DECISIONS.md](DECISIONS.md) is a historical accepted-decision ledger.
- [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md) is a historical and active question
  ledger.

Those files may describe older milestones. Treat the current baseline in
[Bootstrap Status](BOOTSTRAP_STATUS.md) and the root [README](../README.md) as
the present posture.

## Documentation Posture

Docs are governance and orientation material. They must not claim deployment,
public launch, production readiness, full Archive.org search, full web crawling,
download/install capability, native marketplace readiness, AI authority, or
broad corpus coverage unless a future accepted milestone provides evidence and
updates the relevant gates.
