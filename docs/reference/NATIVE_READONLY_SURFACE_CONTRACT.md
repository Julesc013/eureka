# Native Read-Only Surface Contract

`contracts/native/native_readonly_surface.v0.json` describes what a native
read-only client may show.

Supported views are search results, object summary, source summary, relay
status, action manifest, blocked action, and diagnostics. Supported inputs are
local fixture/snapshot/relay/action records only.

Unsupported current features include source probing, connector access, resolver
ownership, downloads, installs, execution, accounts, telemetry, and public or
master index mutation.
