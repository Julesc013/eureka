# Public Alpha Blocker Register

Blocker classes:

- `hard_blocker`: must stop deploy dry-run or launch progression
- `launch_warning`: may allow dry-run progression only with an explicit note
- `accepted_nonblocking_debt`: documented limitation that does not block the
  dry run
- `future_work`: planned work outside the launch-candidate gate

Current launch candidate has no active hard blockers or launch warnings.

Accepted nonblocking debt:

- reviewed corpus remains intentionally limited
- public copy must not imply comprehensive coverage

Future work:

- demand signals
- source request queue
- live metadata pilots
- native read-only clients
