# Snapshot Render Result Contract

`contracts/snapshots/snapshot_render_result.v0.json` defines text, lite HTML, and JSON manifest render outputs.

Render results must preserve identity, title/summary, source posture, evidence posture, compatibility posture where present, rights posture, risk posture, action posture, limitations, and no-claims.

Render results are offline projections. They do not activate public routes, hosting, relay, downloads, mirroring, execution, or public search behavior.
