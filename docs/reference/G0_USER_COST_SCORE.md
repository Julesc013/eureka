# G0 User Cost Score

User-cost scores classify the effort needed to use or review a fixture result.
The record includes a user_cost_class, effort estimate, actionability level,
allowed read-only actions, blocked actions, explanation, uncertainty,
limitations, and future WorkUnit seed suggestion.

User-cost is an estimate only. It cannot claim that an item is downloadable,
safe, executable, installable, verified, or available.
