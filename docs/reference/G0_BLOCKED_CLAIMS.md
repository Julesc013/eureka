# G0 Blocked Claims

G0 must not claim:

- fake evidence or verified records
- accepted identity merges
- live source access
- source probe execution
- downloads or uploads
- extraction
- provider or model use
- operator instance mutation
- master or public index mutation
- deployment
- production readiness
- public launch readiness

Any future task that needs one of these actions must add an explicit policy,
validator, evidence trail, and review gate.
