# Run Coverage Report

`run_coverage_report.v0` summarizes what a dry-run checked and what remains
unchecked.

Checked in the foundation:

- headless run created
- query compiled
- local lane projection
- IA-Hunt WorkUnit dry-run planning
- blocked-action posture

Unchecked:

- live source metadata
- downloads
- extraction
- review/promote/apply
- operator instance apply
- public fanout
