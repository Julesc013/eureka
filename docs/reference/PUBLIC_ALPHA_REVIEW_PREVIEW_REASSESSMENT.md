# Public Alpha Review Preview Reassessment

Review previews are limited readiness signals created by live metadata review.
They may describe:

- reviewed metadata record previews
- reviewed source lead previews
- useful leads
- needs-more-evidence decisions
- rejected or duplicate decisions

They are not accepted truth, verified downloads, safe installers, extracted
files, malware-clean claims, or rights-cleared artifacts.

`PUBLIC-ALPHA-REASSESS-02` counts review previews separately from reviewed
records. Preview count can improve internal demo and review usefulness, but it
cannot satisfy public launch thresholds.

The next gate is local apply. After apply, snapshots and reassessment must run
again before any public alpha launch discussion resumes.
