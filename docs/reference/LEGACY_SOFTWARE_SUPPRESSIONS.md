# Legacy Software Suppressions

The legacy software batch makes suppressions visible in candidate summaries and
review packets.

Required suppressions include:

- `generic_os_iso`
- `operating_system_image`
- `crack`
- `keygen`
- `serial`
- `warez`
- `torrent_only`
- `malware_suspicious`
- `fake_driver_updater`
- `wrong_platform`
- `wrong_version`
- `web_installer_when_offline_requested`
- `unrelated_modern_version`
- `source_only_mention`
- `duplicate`
- `low_metadata_match`
- `unsafe_or_blocked`

All suppressions are review-only evidence and none create accepted truth.
Review override is disabled by default.
