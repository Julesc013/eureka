# Device ID Capture Guide

Use whichever method is available. The goal is to identify the device, not to
install or execute untrusted software.

## Windows 98 Device Manager

1. Open Device Manager.
2. Find the unknown or target device.
3. Open Properties.
4. Record manufacturer, model, device class, resources, and any hardware id or
   compatible id fields that are visible.
5. Record any error code, but do not install a random driver to test it.

## Physical Inspection

Record visible markings:

- vendor name
- model number
- chipset label
- board revision
- FCC ID
- chip part numbers
- slot or interface type

Photos can help, but redact serial numbers if they are not needed.

## Existing Media

For driver discs or floppies, record:

- disc or label title
- vendor and version text
- file or directory names
- readme title or version text
- checksum only if already available from a trusted tool or source

Do not upload binaries into the repo.

## Safety Boundary

This guide does not authorize downloads, executable runs, installer launches,
archive extraction, malware claims, or rights-clearance claims.
