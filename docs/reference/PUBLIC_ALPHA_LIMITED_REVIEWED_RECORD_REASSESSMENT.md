# Public Alpha Limited Reviewed Record Reassessment

Limited reviewed metadata records and reviewed source leads are useful public
alpha signals, but they are limited claims.

They may say:

- Metadata was reviewed under local apply policy.
- A source lead is useful for further review.
- The record is visible in read-only search as a source-lead style result.

They must not say:

- A downloadable artifact is verified.
- A file is malware-clean.
- Rights are cleared.
- Software is installable or executable.
- Public launch is ready.

`PUBLIC-ALPHA-REASSESS-03` counts the current limited projection count of 4 for
internal usefulness. It still blocks launch because the public alpha threshold is
25 reviewed records and at least 3 reviewed domains.
