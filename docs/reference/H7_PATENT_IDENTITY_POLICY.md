# H7 Patent Identity Policy

Patent identity candidates include patent numbers, jurisdictions, filing and publication dates, inventors, assignees, classification, priority, families, citations, and document locators. Patent metadata does not prove legal status, validity, expiry, enforceability, or download permission.

## Current Boundary

H7-BUNDLE-01 is policy-pack-only. It does not enable live access, API queries,
OAI-PMH harvests, DOI/ISBN/patent queries, full-text fetches, downloads, IIIF
fetches, scraping, crawling, restricted-source access, source sync, public index
mutation, master index mutation, or truth acceptance.
