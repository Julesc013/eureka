# G0 Explanation Packet

An explanation packet must include:

- why_result_appeared
- why_result_ranked_here
- why_result_is_limited
- why_actions_are_blocked
- what_would_improve_confidence
- what_remaining_work_exists

The packet can expose matched query terms, aliases, identifiers, domain hints,
source family, metadata fields, member paths, SCOUT relations, reviewed fixture
posture, provisional candidate posture, source-cache-only status, known absence,
near misses, duplicate candidates, uncertain provenance, rights unknown, and
safety unknown.

The packet is not evidence and cannot change ranking or indexes.
