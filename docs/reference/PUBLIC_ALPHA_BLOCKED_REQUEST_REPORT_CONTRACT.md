# Public Alpha Blocked Request Report Contract

Blocked request reports describe unsafe request kinds and the safe local alternative. They must keep download, upload, account, telemetry, live probe, source sync, index write, public relay, and launch claims blocked.

Validation commands are listed in the E-BUNDLE-02 audit pack. All examples preserve no deployment, no provider call, no DNS change, no site/dist mutation, no live fanout, and no production claim.
