# H5 Firmware Update Policy

Firmware/update metadata can describe firmware names, BIOS or UEFI versions, device or board models, hardware revisions, package IDs, release dates, prerequisites, rollback notes, risk warnings, checksum metadata, signature metadata, flashing tool candidates, and blocked action candidates.

Firmware metadata is high risk. H5-BUNDLE-01 does not approve firmware installation, firmware flashing, tool execution, downloads, or compatibility truth. Wrong firmware can damage hardware, so action remains blocked by default.
