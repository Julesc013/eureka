# SearchNeed Record

Required fields include:

- `id`
- `hunt_id`
- `exhaustion_report_id`
- `query`
- `normalized_query`
- `need_title`
- `need_summary`
- `need_kind`
- `desired_outcome`
- `priority`
- `state`
- `local_result_state`
- `checked_layers`
- `deferred_layers`
- `recommended_future_work`
- `policy_limitations`
- `warnings`
- `public_safe_summary_allowed`
- `private_notes_allowed`
- `created_at`
- `updated_at`
- `idempotency_key`
- `superseded_by`

The record is local demand state. It does not authorize acquisition, execution, extraction, source probing, model calls, or index mutation.
