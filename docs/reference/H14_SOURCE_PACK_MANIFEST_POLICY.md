# H14 Source Pack Manifest Policy

H14-BUNDLE-01 defines source pack manifest policy as Source OS policy structure only. It is not
live source discovery, crawling, search, model/provider suggestion, pack import
or export, source registry mutation, connector registry mutation, source-cache
write, evidence write, public-index mutation, master-index mutation, source
approval, connector approval, reliability truth, freshness truth, coverage
truth, dispute truth, revocation truth, lineage truth, launch readiness, or
production readiness.

Current allowed work is committed policy and preview material only: source
records, policy packs, fixture plans, coverage previews, scorecard previews,
and audit summaries. Future H14 work must replay synthetic fixtures before any
runtime work and must pass review gates before discovery, registry changes,
pack import/export, source-cache persistence, evidence acceptance, or public
index use.
