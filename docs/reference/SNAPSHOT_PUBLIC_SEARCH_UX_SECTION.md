# Snapshot Public Search UX Section

Schema: `snapshot_public_search_ux_section.v0`

This section records public UX route refs, page refs, result-card refs, no-results refs, and HTML/text example refs from the public search UX MVP.

Required constants:

- `no_js_required: true`
- `public_read_only: true`
- `mutation_enabled: false`
- `live_source_fanout_enabled: false`
- `download_enabled: false`
- `file_fetch_enabled: false`
- `ocr_enabled: false`
- `extraction_enabled: false`
- `model_provider_enabled: false`
