# Relay Response Contract

`contracts/relay/relay_response.v0.json` defines a renderable relay response.

Responses include status, content type, render profile, semantic fields present,
blocked actions, no-claims, and truth/product boundaries. A response is a local
fixture projection and is not public truth.

Every D-BUNDLE-02 response preserves false values for public/master index
mutation, evidence/candidate acceptance, rights clearance, malware safety, and
verified installability.
