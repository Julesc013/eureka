# Public Search Result Card Reference

Required public card states:

- `verified`
- `reviewed_metadata_record`
- `reviewed_source_lead`
- `candidate`
- `near_miss`
- `known_need`
- `absence`
- `source_lead`

Only `verified` may be accepted reviewed object truth. Reviewed metadata/source-lead cards are limited claims. They remain distinct from verified downloadable artifacts.
