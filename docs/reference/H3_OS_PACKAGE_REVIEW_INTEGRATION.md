# H3_OS_PACKAGE_REVIEW_INTEGRATION

H3 review integration converts fixture replay outputs and blocked live-probe reports into review seeds and previews only. OS package identity, compatibility, dependency/conflict/provides, file/hash, source-cache, and evidence items remain candidates and are not accepted truth.

Validation commands: `python scripts/validate_h3_os_package_review_quality_audit.py`, `python scripts/audit_h3_os_package_archive_wave.py --check`, and focused H3 review unit tests.
