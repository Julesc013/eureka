# Source Capability Contract

Source capabilities describe what a source appears able to support under an
approved policy. They do not grant permission.

The H0 ladder is:

- `source_known`
- `catalog_indexed`
- `metadata_indexed`
- `representation_indexed`
- `content_indexed`
- `action_indexed`

Discrete capabilities include documented APIs, identifier lookup, search,
pagination, bulk dumps, metadata record fetches, file/member listings, hashes,
release assets, reviews or notes, compatibility notes, OAI-PMH, IIIF, CDX,
RSS/Atom/sitemap, directory listing, auth-required future access, local-only
import, and restricted manifest-only representation.
