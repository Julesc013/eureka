# Reference Docs

This directory contains stable reference material: contracts, API envelopes,
schemas, command policies, and governed public/status vocabularies.

Reference docs define boundaries and packet shapes. They do not, by themselves,
enable runtime behavior, hosted deployment, live source calls, downloads,
uploads, public mutation, model/provider calls, or truth acceptance.

## Claim Rule

If a reference document describes a future route, capability, contract, or
manifest, look for implementation, validator, test, and audit evidence before
treating it as current behavior.
