# Driver Support Suppressions

The driver/support seed batch blocks or routes these conditions to review:

- fake_driver_updater
- driver_booster_or_updater_tool
- crack
- keygen
- serial
- warez
- torrent_only
- malware_suspicious
- executable_download_when_metadata_only
- wrong_hardware_model
- wrong_os_version
- wrong_architecture
- wrong_vendor
- unrelated_modern_driver
- web_installer_when_offline_requested
- unsupported_repack
- generic_search_result
- source_only_mention
- duplicate
- low_metadata_match
- unsafe_or_blocked

Suppression records prevent the seed batch from implying a safe driver,
installable package, compatible OS/hardware pairing, or lawful distribution.
Review can use suppressed evidence as a lead, but this task does not promote it.
