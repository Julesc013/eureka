# Prohibited Claims

This handoff keeps artifact evidence honest. External/manual observations may
support a future review step, but they do not become product truth on arrival.

## Prohibited Without Future Review

- reviewed artifact record created
- verified artifact created
- public artifact availability
- safe download
- safe installation
- executable safety
- malware clean
- rights cleared
- license cleared
- compatibility proven
- Windows 98 driver recommendation
- source truth accepted
- public alpha ready
- `dev -> main` ready
- production ready

## Required Wording

Use bounded terms:

- `observed`
- `source-referenced`
- `candidate`
- `reviewable`
- `needs more evidence`
- `blocked for user details`
- `not found`
- `deferred`

Avoid unqualified terms:

- `verified`
- `safe`
- `official` unless the source identity proves that status
- `downloadable`
- `compatible`
- `complete`
- `ready`

## Windows 98 Driver Boundary

The Windows 98 driver query remains blocked until the user supplies hardware
identity details. Do not recommend a specific driver based only on generic OS,
vendor-family, or search-result evidence.
