# Manuals/Scans Suppressions

Required suppressions:

- `full_book_download_when_metadata_only`
- `rights_claim_missing`
- `scan_completeness_unknown`
- `ocr_quality_unknown`
- `wrong_model`
- `wrong_manual_type`
- `wrong_platform`
- `wrong_version`
- `generic_search_result`
- `source_only_mention`
- `duplicate`
- `low_metadata_match`
- `unsafe_or_blocked`
- `executable_download`
- `software_installer_result`
- `unrelated_modern_documentation`

Suppressions are review signals, not truth. They prevent metadata-only results
from being mistaken for reviewed document artifacts.
