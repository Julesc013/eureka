# H1 Metadata Normalized Record

The normalized record is a source observation preview derived from committed fixtures. It carries source identity, title, version/state, artifact family, fixture locator, metadata summaries, source-cache preview, evidence preview, truth boundary, product boundary, and limitations.

Missing optional fields are represented as `unknown` or limitations. They are not fabricated.

Normalized records are not accepted evidence, accepted source truth, public records, rights clearance, malware safety, or verified installability.
