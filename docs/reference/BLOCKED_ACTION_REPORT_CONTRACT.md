# Blocked Action Report Contract

`contracts/schema/control/audits/actions/blocked_action_report.v0.json` explains why a risky action is unavailable.

Blocked action reports cover future risky actions such as download, mirror, install, execute, emulate, submit, and import. They include required policy/review gates and safe alternatives such as view, inspect, cite, export, preservation manifest, and acquisition manifest.

A blocked action report does not perform the blocked action and does not authorize later action execution.
