# H9 Media Safety Privacy Policy

H9 is a policy-pack-only wave for media, music, image, video, audio, map, museum/art, open-media, and fingerprint metadata sources.

The wave selects public and policy-limited metadata sources so later H9 bundles can rehearse fixture normalization before any approved live metadata probe. It reuses Source OS boundaries from H0-H8: source observations can become candidates and previews, never accepted truth.

Candidate areas include media object identity, music work/recording/release identity, image/video/map identity, creator/collection relations, media fingerprint metadata, rights/license metadata, and safety/privacy metadata. Each candidate area requires review before source-cache use, evidence acceptance, public index use, or master index use.

Current status is policy_pack_only. H9-BUNDLE-01 enables no live access, API query, catalog fetch, image/video/audio/map/score/thumbnail download, media upload, fingerprint lookup, fingerprint submission, fingerprint generation, scraping, crawling, browser automation, bypass, restricted-source access, public query fanout, source sync, public index mutation, or master index mutation.

Metadata fields do not prove media authenticity, audio identity, image identity, rights clearance, public-domain status, Creative Commons validity, attribution correctness, malware safety, privacy safety, content safety, or production media coverage.

H9-BUNDLE-02 is expected to add fixture runtimes and normalizers using committed public-safe fixtures only. H9-BUNDLE-03 may add approved metadata-only live probes after policy review.

Validation commands: `python scripts/validate_h9_media_metadata_policy_packs.py`, `python scripts/summarize_h9_media_metadata_sources.py --check`, and the relevant unit tests.
