# SCOUT Relation Types

SCOUT is relation/path discovery, not search replacement and not truth. SCOUT
outputs are candidates, observations, and suggestions that require review before
anything can become evidence or a reviewed record. There is no live source call,
no live source behavior, no crawling, no download, no extraction, no model call,
and no deployment in this foundation.

SCOUT connects DOMAIN interpretation hints, SYN pressure cases, IA-HUNT metadata
outputs, future F0 extraction policy, and future G0 ranking/explanation work by
naming candidate relation trails and source trust inputs. Engagement optimization
is forbidden; usefulness, provenance, evidence quality, and hard-find value are
higher-priority signals.
