# Extraction Member Contract

`contracts/extraction/extraction_member.v0.json` describes archive members found during Tier 1 listing. F-BUNDLE-01 members include raw and normalized member paths, kind, size metadata, manifest-like hints, block reasons, path safety, preview allowance, and hard `extracted_payload_stored: false`.

Unsafe members are listed as blocked. They are not extracted to disk and are not evidence truth.
