# Native Manual Smoke Checklist Contract

`contracts/native/native_manual_smoke_checklist.v0.json` defines manual checks
for first-wave native clients.

Required checks include project open, build, launch, snapshot fixture display,
relay status display, search list display, object summary display, blocked
action display, no risky action behavior, and diagnostics/about display.

Checklist results remain evidence for review. They do not accept truth or
authorize downloads, installs, execution, telemetry, or index mutation.
