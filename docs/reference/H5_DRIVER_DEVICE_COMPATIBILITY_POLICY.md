# H5 Driver Device Compatibility Policy

Driver/device compatibility metadata can describe driver names, driver versions, device IDs, hardware models, operating systems, architectures, driver classes, chipset/component fields, known issues, install requirements, reboot requirements, and signature metadata candidates.

Compatibility candidates are not verified compatibility. Device ID, OS, and architecture matches do not prove safe installability or runtime correctness, and signature metadata is not authenticity until a future verifier policy exists.
