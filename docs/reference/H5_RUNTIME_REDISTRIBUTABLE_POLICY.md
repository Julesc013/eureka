# H5 Runtime Redistributable Policy

Runtime redistributable metadata can describe runtime families, versions, installers, architectures, operating systems, redistributable IDs, dependencies, security update candidates, end-of-life candidates, hash metadata, signature metadata, and download locator candidates.

Runtime candidates are not installability truth. Installer metadata is not execution permission, dependency metadata is not dependency correctness, and hash/signature metadata is not verified authenticity or safety.
