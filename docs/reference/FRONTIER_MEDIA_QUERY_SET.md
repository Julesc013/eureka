# Frontier Media Query Set

The seed batch uses twelve curated queries focused on early high-definition,
D-Theater, D-VHS, Hi-Vision, MUSE, HDVS, and related city-footage provenance
leads.

The canonical machine-readable matrix is:

```text
control/inventory/seed_batch_frontier_media_query_matrix.json
```

Every query is assigned:

- intent: `find_frontier_resolution_media`
- domain: `frontier_resolution_media`
- expected sources: Archive.org metadata, Wayback/CDX metadata descriptors,
  Wikidata descriptors, and manual source-pack replay
- candidate posture: review-only
