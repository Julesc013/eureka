# H5 Vendor Identity Policy

Vendor identity fields are candidates only. A source may expose vendor names, product names, support page references, catalog IDs, update IDs, download IDs, version fields, advisory references, release-note references, locator candidates, and hash or signature metadata references.

These fields do not prove official status, compatibility, availability, safety, endorsement, rights clearance, or authenticity. Review is required before any source-cache persistence, evidence acceptance, public index use, or master index use.
