# Aggregation Packet — Eureka HUNT, IA, SYN, and Artefact Resolution Planning

## One-Paragraph Summary

This chat documents the convergence of Eureka from a scaffold-heavy, task-driven repository into a local-first universal artefact-resolution engine. The conversation moves through production-reality recovery, Local Appliance design, HUNT search-investigation architecture, branch/AIDE quality gates, PLAY local usability, Internet Archive metadata pilot, and a larger roadmap involving SYN, DOMAIN, SCOUT, F extraction, ranking, source expansion, packs, actions, AI, snapshots, clients, hosting, and ecosystem work. The most recent visible state says `dev` has Local + HUNT + PLAY + IA metadata pilot through reviewed local index proof, but `dev` is ahead of `main`; this must be verified before execution. The strongest future product target is a progressive local HTML search page that returns reviewed local results first, then IA cache, metadata, item/file manifests, candidates, review state, and reviewed-index updates, with extraction and downloads deferred to later gates.
