# Decision Docket

## Settled decisions

- Eureka is an evidence-first temporal artefact/object resolver rather than an answer-first search engine.
- Reviewed evidence is the truth boundary; candidates, metadata, synthetic examples, and AI outputs are not truth.
- Public search must be bounded and must not fan out live to arbitrary sources in the near term.
- Dry-runs precede authoritative runtimes and must not be mistaken for production stores.
- The Workbench should be the internal/operator superset of the final product.
- IA metadata is the first source-family proof, but it is not full Archive.org integration.
- SYN creates evaluation pressure, not fake evidence.
- AIDE/Codex control packets are process metadata, not product truth.
- Current repo authority outranks archive reports and chat memory.
- One semantic model should project into many representations; separate client truth models are rejected.

## Tentative decisions

- Insert Track 0 before Track A to reconcile P-number queues, tracks, idempotence, state pointers, and commit conventions.
- Make TSIS/Track A representation contracts the next architecture doctrine before more product expansion.
- Prioritize ResolutionRunKernel and Workbench live-run flow before broad source-wave expansion.
- Use DOMAIN packs, SCOUT, and F extraction as staged expansion after Workbench/source/eval proof.
- Let manual observations become agent-assisted review queues while preserving anti-fabrication rules.

## Superseded decisions or directions

- Public alpha as the immediate milestone from a thin corpus is superseded by reviewed-corpus growth and local product proof.
- One-off source scripts are superseded by a reusable run kernel, WorkUnit scheduler, lane projector, source adapters, and review bridge.
- Prompt-vocabulary architecture is superseded by domain/runtime/contract vocabulary.
- “Same UI code everywhere” is superseded by same contracts and many negotiated renderers.
