# Rejected or Superseded Ideas

- Public launch from an empty or tiny reviewed corpus.
- Public search live fanout to Internet Archive, Wayback, GitHub, PyPI, npm, Software Heritage, arbitrary URLs, or connector runtimes without approval.
- Synchronous “search all Archive.org deeply while the user waits.”
- Treating IA metadata as verified object truth.
- Downloads, installs, package managers, emulators, VMs, malware/rights/installability claims, or marketplace behavior as near-term defaults.
- AI/model answer generation as product truth.
- Synthetic queries generating evidence or verified records.
- Broad source-wave expansion before a reusable run/source/review architecture exists.
- Directly wiring Workbench pages to IA-specific scripts.
- Native/mobile clients consuming backend internals instead of snapshots/relay/API projections.
- Top-level directory sprawl for renderers/skins/services/apps/data/infra if current roots can contain TSIS cleanly.
- Prompt/task/audit vocabulary leaking into runtime domain architecture.
- Treating generated AIDE/repo-health state as more authoritative than live repo state.
