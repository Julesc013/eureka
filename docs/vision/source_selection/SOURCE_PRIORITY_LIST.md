# Source Priority List

Priority order used for corpus synthesis:

1. `source_blocks_for_future_book.md` — highest signal for project-bearing passages.
2. `decisions_open_questions_next_steps.md` — strongest source for docket, open questions, rejected directions, and roadmap.
3. `current_state_summary.md` — best source for current-reality caveats, blocked points, and verification needs.
4. `human_archive_report.md` — narrative context and rationale; selected but downweighted because much overlaps with the previous three.
5. Loose TSIS markdowns — later advisory doctrine on representation, surface kernels, and root structure; used as supplemental design intent.
6. `artifacts_and_prompts.md`, `aggregation_packet.md`, `quality_audit.md` — reference layer only.

Priority is not authority. Current repo authority, if supplied later, outranks all archive-derived claims.
