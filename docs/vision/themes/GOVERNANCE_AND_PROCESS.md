# Governance and Process

The corpus is unusually strong on governance. It insists that archive claims are advisory, generated state may be stale, candidates are not truth, synthetic data creates pressure but not evidence, and review is the truth boundary.

## Key synthesis

Settled process decisions include dry-run before authoritative runtime, connector approval before runtime, external full-discovery outside AI, blocker resolution inside self-contained Codex prompts where safe, and branch/AIDE synchronization before expansion.

## Unresolved questions

Open questions include the live repo state, whether branch promotion has occurred, whether Manual Observation Batch 0 is complete, and what source policy authorizes first live metadata probes.

## Contradictions or drift

The clearest contradiction is stale generated repo state versus live branch comparison in one chat. The corpus resolves it by treating live repo authority as superior to generated summaries, and current repo authority as superior to all chat archives.

## Implications for future work

Future queue tasks should include explicit authority labels, source restrictions, validation reports, no promotion of archive claims, no canonical mutation from candidates, and compact external full-discovery summaries for AI review.
