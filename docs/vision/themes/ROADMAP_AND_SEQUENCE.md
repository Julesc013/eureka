# Roadmap and Sequencing

The corpus contains several overlapping roadmaps: P-number prompts through P107, a track plan, a Workbench/IA/SYN sequence, and later TSIS/source-snapshot closeout notes. The clean synthesis is to stop expanding prompts, verify current state, establish semantic/representation contracts, and then prove the run/workbench/source loop.

## Key synthesis

Most settled sequence constraints are negative: do not launch public production now, do not add all sources now, do not search all IA synchronously, do not do downloads/extraction/AI truth now, and do not make native/marketplace work depend on backend internals.

## Unresolved questions

Open sequencing questions include whether Track 0 is formally inserted, whether Track A/TSIS or ResolutionRunKernel comes first, whether SYN precedes IA-DEEP, and where Manual Observation Batch 0 fits after representation contracts.

## Contradictions or drift

The drift is from public-alpha hardening to corpus-growth/local-workbench proof, then to track convergence, and finally to TSIS as the representation doctrine. This is not a contradiction if treated as layers: closeout, contracts, workbench proof, source expansion, publication.

## Implications for future work

The clean near-term sequence is: finish this corpus; write the book; verify repo/current authority; run source/snapshot baseline closeout; add TSIS doctrine/contracts; establish run/surface kernels; build Workbench-visible progressive IA metadata lane; then expand through SYN, DOMAIN, SCOUT, and F.
