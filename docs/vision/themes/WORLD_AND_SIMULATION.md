# World and Simulation

This corpus contains little evidence for game-world, civilization, economy, planetary, or simulation-OS design. The project-bearing “world” material is instead temporal/domain breadth: old software, drivers, manuals, hidden archive members, source packages, advanced-format media, provenance-obscured cultural artefacts, and domain packs.

## Key synthesis

The strongest relevant decision is domain-pack modularity: broad future coverage should be added through typed domain packs, not hardcoded into the kernel.

## Unresolved questions

Open questions include how soon frontier-resolution media becomes a formal domain pack and what minimum object model is needed for non-software artefacts.

## Contradictions or drift

The main absence is important: the supplied Eureka zips do not substantiate Domino/Dominium, worldgen, planets, celestial systems, civilization, economy, or logistics as active current themes. Those should not be written into the vision from this corpus alone.

## Implications for future work

Future work should treat frontier-resolution media as a second wedge only after the resolver loop is stable: DOMAIN packs before broad domain expansion, SCOUT for relation discovery, and F extraction for hidden-member discovery.
