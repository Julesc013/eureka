# Go No-Go Checklist

## Go Requires

- public scope accepted
- launch deferral lifted by explicit decision
- fallback/usefulness/corpus gates pass
- public routes read-only
- Workbench private
- unsafe actions disabled
- rollback rehearsed
- monitoring ready
- takedown/risk process ready
- manual approval recorded

## No-Go If

- public live fanout is enabled without gate
- reviewed records lack review events
- fallback results appear verified
- source observations mutate reviewed truth
- Workbench action leaks public
- public launch approval is inferred rather than recorded
