# Public Alpha Launch Plan

Launch is future-gated and manually approved.

## Launch Scope

- read-only public search
- reviewed objects
- candidates
- needs
- near misses
- source observations
- evidence summaries
- method/about/status pages

## Launch Non-Goals

No downloads, installs, emulation, marketplace behavior, public writes, public
candidate promotion, arbitrary live fanout, deep crawling, full Archive.org
integration, or AI answer truth.
