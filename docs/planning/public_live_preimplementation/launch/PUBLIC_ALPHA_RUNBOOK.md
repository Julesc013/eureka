# Public Alpha Runbook

1. Confirm authority and queue state.
2. Confirm no public mutation, downloads, extraction, source fanout, or
   model/provider calls are enabled.
3. Run public read-only validators.
4. Run fallback/source disable switch checks.
5. Run search usefulness eval.
6. Confirm reviewed seed corpus gate.
7. Confirm operations rollback and safe mode.
8. Record manual launch approval.
9. Deploy only through reviewed release procedure.
10. Monitor, with rollback ready.
