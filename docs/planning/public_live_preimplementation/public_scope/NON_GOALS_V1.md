# Non-Goals V1

Public v1 must not include:

- downloads
- installs
- emulation launch
- extraction runs
- marketplace behavior
- public write access
- public candidate promotion
- arbitrary public source lookup
- deep crawling
- full Archive.org integration
- AI/model output as truth
- automatic public/master index mutation
- rights clearance claims
- malware or safety proof claims
- broad corpus coverage claims
- production readiness without release gates
