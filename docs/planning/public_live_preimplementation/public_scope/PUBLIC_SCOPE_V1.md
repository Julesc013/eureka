# Public Scope V1

Public v1 is a read-only, evidence-first temporal artefact resolver.

## In Scope

- bounded public search
- reviewed records
- candidate records
- needs
- near misses
- bounded absences
- source observations
- evidence summaries
- public status and method pages
- policy labels and blocked reasons
- read-only API or JSON projection where already governed
- snapshot/static projections

## Out Of Scope

Downloads, installs, emulation, marketplace behavior, public write access,
public candidate promotion, arbitrary source fanout, deep crawling, full
Archive.org integration, AI answer truth, rights clearance claims, and
malware/safety proof claims.

## Scope Gate

A public user must be able to see what is verified, what is candidate, what is
missing, why a result matched, what evidence exists, and which actions are
allowed or blocked.
