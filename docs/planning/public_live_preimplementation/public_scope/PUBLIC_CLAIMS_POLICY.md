# Public Claims Policy

## Allowed Claims

- Eureka is evidence-first.
- Public alpha is read-only if gates pass.
- Candidate and need states are visible.
- Source observations are evidence, not truth.
- Public mutation and dangerous actions are disabled.
- Coverage is bounded and incomplete.

## Forbidden Claims

- public launch before approval
- production readiness before release gates
- broad corpus coverage
- full Archive.org integration
- rights clearance
- malware/safety proof
- AI answer truth
- verified download availability
- guaranteed compatibility
- exhaustive source search

## Wording Rule

Use "reviewed", "candidate", "need", "near_miss", or "policy_blocked" instead
of promotional certainty when evidence is incomplete.
