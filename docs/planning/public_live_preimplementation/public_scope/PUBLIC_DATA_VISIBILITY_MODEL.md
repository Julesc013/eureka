# Public Data Visibility Model

## Public-Safe

- reviewed public records
- public candidates
- public SearchNeeds
- public near misses
- public bounded absences
- public-safe source observations
- evidence summaries with no private/raw sensitive material
- policy labels and blocked reasons
- public-safe manifests/citations

## Operator-Only

- review actions
- promotion/rejection flows
- private local records
- raw source responses unless explicitly public-safe
- tokens, secrets, local instance paths
- private Workbench diagnostics
- unredacted query logs

## Rule

Public visibility must be decided before rendering. Renderers project already
filtered view models.
