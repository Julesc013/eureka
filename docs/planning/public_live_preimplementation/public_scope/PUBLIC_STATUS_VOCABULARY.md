# Public Status Vocabulary

Use these canonical statuses:

| Status | Meaning |
| --- | --- |
| `verified` | reviewed truth with required evidence/review event |
| `candidate` | plausible lead not promoted by review |
| `need` | missing information or object need |
| `near_miss` | close but not exact match |
| `mention_only` | source mention without enough candidate evidence |
| `policy_blocked` | blocked by policy, safety, privacy, or source rule |
| `private_local` | not public-safe |
| `superseded` | replaced by later reviewed state |
| `rejected` | rejected by review |
| `unknown` | unknown or forward-compatible fallback |

Avoid public synonyms such as `maybe`, `candidate-ish`, `semi_verified`, or
`provisional`.
