# Public Alpha Launch Gates

Public alpha remains deferred until all gates pass.

## Required Gates

- public scope written and accepted
- non-goals written and accepted
- public actions policy enforced
- no public writes
- no public downloads, installs, extraction, or emulation
- no public arbitrary source fanout
- Workbench private
- review ledger active for truth promotion
- indexless fallback implemented as a run mode if used
- fallback/source disable switches tested
- hard-query usefulness evaluation passed
- reviewed artifact record gate passed
- reviewed seed corpus threshold met
- rollback runbook verified
- query privacy and takedown posture documented
- manual launch approval recorded

Existing launch-candidate and deploy-dry-run evidence can be reused as prior
evidence, but it does not override launch deferral.
