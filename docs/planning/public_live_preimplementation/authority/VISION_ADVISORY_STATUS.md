# Vision Advisory Status

`docs/vision/**` exists and is tracked. It contains product thesis, doctrine,
source blocks, synthesis, extracted archive packets, raw zip packages, and
review material.

For this package, all `docs/vision/**` claims are advisory unless independently
confirmed by current repo authority. Vision material may shape roadmap language,
but it must not override:

- current README status
- checked-in contracts
- queue index
- current inventory results
- launch deferral evidence
- component boundary rules

## Advisory Claims That Need Care

- Long-horizon client/rendering/plugin ambitions.
- Complete source-family ecosystem claims.
- Full public/live product shape.
- Anything implying downloads, extraction, marketplace behavior, or public live
  fanout.

## Accepted Use

Use vision material to preserve doctrine: evidence-first search, review truth
boundary, source observations as evidence, surface-neutral semantics, and
closed-root architecture.
