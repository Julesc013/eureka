# Incident Response Plan

1. Classify incident.
2. Freeze unsafe path.
3. Preserve evidence.
4. Disable source/fallback/review/render path if needed.
5. Roll back deploy/index/snapshot if needed.
6. Communicate public status if public-facing.
7. Write post-incident review.

Incidents include source outage, privacy-sensitive query exposure, rights or
takedown complaint, bad reviewed promotion, and route/action policy failure.
