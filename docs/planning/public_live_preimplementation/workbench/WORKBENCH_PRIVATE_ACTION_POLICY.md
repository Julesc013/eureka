# Workbench Private Action Policy

## Operator-Only Actions

- `review_candidate`
- `promote`
- `reject`
- `supersede`
- `request_more_evidence`
- `mark_need`
- `mark_policy_blocked`
- `rebuild_index`
- `freeze_review`
- `inspect_run`
- `inspect_source_observation`

## Controls

- require operator auth
- record audit events
- reject public route invocation
- preserve rollback/supersession evidence
- require evidence or rationale for review decisions
