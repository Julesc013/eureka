# PUBLIC-ALPHA-LAUNCH-00

Goal: launch read-only public alpha only after explicit manual approval.

Inputs to read first: readiness report, go/no-go checklist, release hosting
artifacts, security review.

Allowed paths: release/hosting, operations evidence, public deployment paths
authorized by operator approval.

Protected paths: public mutation, unsafe actions, source fanout, downloads.

Deliverables: launch evidence, rollback evidence, public status report.

Non-goals: beta/1.0, public writes, production maturity claims.

Validation: deploy smoke, route read-only, rollback, monitoring, security.

Exit criteria: public launch performed only with recorded approval, or stopped.

Impact statement: release/deployment impact required.
