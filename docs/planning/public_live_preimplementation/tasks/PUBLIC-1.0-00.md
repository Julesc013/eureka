# PUBLIC-1.0-00

Goal: declare a stable public product after beta evidence.

Inputs to read first: beta evidence, security review, data governance, release
notes, public docs.

Allowed paths: release, docs, contracts/API versioning paths if authorized.

Protected paths: unreviewed scope expansion.

Deliverables: stable scope, stable contracts, stable deployment, stable review
loop, security/risk/takedown process, documented method/evidence model.

Non-goals: long-horizon plugin/native/action ecosystem unless separately
gated.

Validation: release gate, security gate, API/export stability gate, rollback.

Exit criteria: Eureka can be publicly described without repo-state caveats.

Impact statement: public/release/contract impact.
