# Risk Register

| Risk | Control |
| --- | --- |
| Fallback becomes a UI-to-source shortcut | Require fallback to enter through ResolutionRunKernel |
| Source metadata is overstated as truth | Label as SourceObservation, EvidenceCandidate, or SearchNeed only |
| Existing repo paths are duplicated | Start with a gap audit against existing contracts/runtime |
| Public launch restarts too early | Preserve launch deferral until usefulness/corpus gates pass |
| Workbench gains private truth semantics | Require Workbench to consume shared run/evidence/review packets |
| Renderer divergence | Use semantic renderer parity and representation profile tests |
| IA metadata expands into crawling/downloads | Keep metadata-only scope and source/action policy gates |
| Vision corpus claims become product claims | Keep vision advisory and require repo-backed verification |
| Full discovery consumes AI session | Use external harness/CI compact summaries only |
