# Search Usefulness Scorecard

| Dimension | Question |
| --- | --- |
| status honesty | Is verified/candidate/need/near_miss/policy_blocked clear? |
| evidence | Can the user inspect why this matched? |
| actionability | Is the next safe action obvious? |
| ambiguity handling | Does the result explain missing information? |
| source posture | Are source limits visible? |
| public safety | Are unsafe actions blocked? |
| improvement output | Does failure create a need or concrete task? |

Score each query 0 to 2 per dimension. Launch gate threshold should be set by a
future reviewed eval task.
