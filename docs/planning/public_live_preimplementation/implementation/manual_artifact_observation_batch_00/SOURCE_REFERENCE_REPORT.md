# Source Reference Report

The batch uses manual references already represented in repo-local eval and review files. It does not perform runtime source calls or live crawling.

Source posture:

- Official/publisher references: artifact identity or support leads only.
- Manual-index/community references: near-miss or lower-confidence leads.
- Windows 98 driver query: no source selected because hardware identity is missing.

Every source record is marked `manual_reference_only: true`.
