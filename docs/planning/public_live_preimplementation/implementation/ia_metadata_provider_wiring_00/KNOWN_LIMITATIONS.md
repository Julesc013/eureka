# Known Limitations

This is a bounded product proof, not a full IA integration.

```text
live network not required
no crawling
no downloads
no file fetching
no Wayback replay
no file/member extraction
no artifact verification
no rights or safety claims
no public alpha readiness claim
no dev -> main promotion claim
```

The smoke uses deterministic fixtures. Live IA metadata execution remains
governed by separate live-metadata lane policy and operator approval.
