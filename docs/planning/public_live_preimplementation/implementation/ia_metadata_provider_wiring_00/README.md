# IA Metadata Provider Wiring 00

Task: `IA-METADATA-PROVIDER-WIRING-AND-SMOKE-00`

This package records the bounded IA metadata provider smoke implementation.

It proves that Eureka can route a local search miss through the existing
resolution-run fallback seam, use fixture-backed IA metadata, preserve honest
non-truth states, project the result through SurfaceKernel, and render it with
the baseline renderers.

It does not launch public alpha, promote `dev -> main`, fetch files, download
artifacts, replay Wayback captures, verify artifacts, or mutate reviewed,
public, or master indexes.
