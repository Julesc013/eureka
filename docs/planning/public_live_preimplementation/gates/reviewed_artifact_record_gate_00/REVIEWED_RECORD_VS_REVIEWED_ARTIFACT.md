# Reviewed Record vs Reviewed Artifact

A reviewed record can be a reviewed support fact. That does not make it a reviewed artifact record.

Current examples:

- `reviewed_seed_hq_windows_7_firefox_115_support_fact`: reviewed support fact about Windows 7 support posture.
- `reviewed_seed_hq_firefox_xp_52_9_support_fact`: reviewed support fact about XP support ending.
- `reviewed_seed_b01_hq_windows_7_7zip_support_fact`: reviewed support fact about a Windows 7 compatible application lead.

These are useful, but they do not prove exact package identity, integrity, acquisition path, safety posture, or rights posture.

Public copy may say reviewed support fact. It must not say reviewed artifact or verified artifact.
