# Source Reference Limits

The source references in this gate come from prior manual observation and review batches. No runtime live source call was performed by this task.

Reference posture:

- Mozilla and 7-Zip references are support-fact leads, not package verification.
- SmartFTP, Core FTP, DOSDays, Manualslib, author pages, and paper/project pages are source or near-miss leads.
- The Windows 98 driver query has no artifact source reference because user hardware identity is missing.

Source references do not self-promote into reviewed artifact records.
