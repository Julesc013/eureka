# Artifact Evidence Levels

| Level | Meaning | Reviewed Artifact? | Verified Artifact? |
|---|---|---:|---:|
| `artifact_level_0_mention_only` | A mention of object, topic, title, model, product, or article. | No | No |
| `artifact_level_1_metadata_or_source_lead` | A metadata, support, catalog, manual-index, article-reference, or source lead. | No | No |
| `artifact_level_2_source_observed_artifact_listing` | A source explicitly lists a specific artifact-like item. | No | No |
| `artifact_level_3_artifact_identity_evidence` | Evidence supports a specific artifact identity. | Yes, with review | No |
| `artifact_level_4_artifact_integrity_evidence` | Evidence includes integrity-bearing details such as hash, size, filename, media ID, package manifest, catalog number, or independent listing. | Yes, with review | No |
| `artifact_level_5_verified_acquisition_or_reproducibility_path` | Evidence supports reproducible acquisition and required posture disclaimers. | Yes, with review | Yes, with review |

This gate records current evidence at levels 0-2 only. No current record qualifies as a reviewed artifact record.
