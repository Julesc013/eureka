# Reviewed Record Definition

A reviewed record includes:

- stable ID
- title/name
- object type
- canonical status
- platform/time/source hints where relevant
- review event reference
- evidence references
- source observation references
- risk/rights posture
- compatibility posture if relevant
- known gaps or absence notes
- public visibility posture
- supersession/rejection link if relevant

No record is reviewed without a review event.
