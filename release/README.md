# Release

`release/` contains release, hosting, rollback, and deployment-planning
materials.

Current release material is planning and gate evidence only. It does not deploy
Eureka, publish a public service, claim production readiness, claim public
launch readiness, enable public mutation, enable live source fanout, or enable
downloads/uploads/extraction/model-provider calls.

High-traffic area:

- `hosting/`: public-alpha deploy dry-run, environment, rollback, and launch
  candidate planning material.

Launch requires explicit manual approval and a reviewed launch task.
