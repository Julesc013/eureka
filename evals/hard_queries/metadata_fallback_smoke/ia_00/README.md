# IA Metadata Fallback Smoke 00

This fixture package proves a bounded IA metadata fallback path without live
network dependency.

The smoke uses repo-local fixtures and the existing resolution-run fallback seam.
IA metadata remains candidate/source-observation support only.

Forbidden in this package:

```text
downloads
file fetching
Wayback replay
artifact verification
rights clearance
malware or safety proof
reviewed/public/master index mutation
public route direct source calls
```
